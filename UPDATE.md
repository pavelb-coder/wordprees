# WP Olympiad 1.0.1 — обновление фонового импорта

Исправление случая: вопросы загружались только после открытия раздела «Вопросы» и обновления страницы.

## Что сделать в WordPress

1. Сделайте резервную копию сайта/базы данных обычным способом.
2. Откройте **Плагины → Добавить плагин → Загрузить плагин** и выберите `wp-olympiad-1.0.1.zip`. Подтвердите замену уже установленной версии. Не удаляйте плагин с удалением данных.
3. В настройках нужной олимпиады откройте **«Подключение к сетевой папке»**. Проверьте путь и реквизиты, включите **«Автоматически импортировать задания из сетевой папки»**, выберите **«Каждую минуту»** и сохраните. Старый явный интервал «Каждый час» автоматически не заменяется.
4. Сохраните новый файл вопросов на сетевом хранилище. При следующей доступной минутной проверке он будет обработан **без открытия конструктора и ручной перезагрузки**.
5. В блоке **«Фоновая синхронизация»** посмотрите последнюю проверку, источник и сообщение. «Файл не изменился» — нормальный результат; дата последней загрузки вопросов при этом не должна меняться. Ошибка чтения/сети отображается отдельно, без удаления существующих вопросов.

Работают штатный WP-Cron и резервная проверка на обычных запросах к WordPress. Пока администратор находится на любой странице панели управления, источником запросов также служит heartbeat WordPress. Открывать именно «Вопросы» больше не нужно.

## Если сайт должен обновляться даже без посетителей

PHP не выполняет задания сам по часам. В блоке синхронизации разверните **«Работа без посетителей / внешний планировщик»**, скопируйте готовый URL и передайте администратору хостинга либо задайте в доверенном внешнем планировщике **GET раз в минуту** к этому URL.

- Используется обычный `wp-cron.php` вашего WordPress; отдельный открытый API импорта не создаётся.
- Не добавляйте `doing_wp_cron=1`.
- Планировщик должен получать реальный ответ WordPress, а не страницу входа, запрет защиты хостинга или кеш.
- Если доступа к хостингу нет, резервная проверка продолжит работать при обращениях к PHP сайта / heartbeat админки. Полностью неактивный сайт без внешнего планировщика не может гарантировать запуск каждую минуту.
- Большая очередь, медленное хранилище, сетевые ошибки и ограничения PHP могут увеличить задержку.

## Сохранность данных

- Обычный повтор уже импортированного неизменённого файла не добавляет копии вопросов. Изменённый файл в режиме **Append** по-прежнему добавляет все вопросы этого файла; **Replace** намеренно заменяет текущий список.
- Файлы вопросов, проекты `.wpoq`, ответы и посторонние файлы сетевой папки не изменяются. В `import/` по-прежнему размещаются только четыре собственных файла программы редактора.
- Чистый открытый конструктор обновляет список автоматически. Если есть несохранённые правки или открыто окно, перезагрузка блокируется и показывается уведомление. Явное обновление списка запрашивает подтверждение; форма настроек не перезагружается автоматически.
- Windows-редактор остаётся версии 1.0.0 и не пересобирался; исправление относится к плагину 1.0.1.

Проверено на отдельном стенде: 103/103 теста плагина и 39/39 проверок реальных запросов/браузера. Это не установка и не проверка на вашем действующем сайте или NAS.

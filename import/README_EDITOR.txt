РЕДАКТОР ВОПРОСОВ WP OLYMPIAD — Windows 10/11 x64

1. Откройте QuestionStudio.exe на ПК с Windows двойным щелчком.
   Установка, Excel и интернет для работы редактора не нужны.
   Если запуск с сетевого диска недоступен, скопируйте EXE на ПК.
   Сетевые права и корпоративные ограничения уточните у администратора.
2. Создайте вопросы; правильные ответы отметьте слева. Все 13 типов доступны.
   Справка → Загрузить примеры показывает образцы каждого типа.
3. «Сохранить» создаёт редактируемый проект .wpoq. Не загружайте его в плагин.
4. «Проверить» находит ошибки. «Экспорт → Excel (.xlsx)» создаёт файл для импорта.
   Также доступны CSV UTF-8 и JSON.
5. Сохраните экспортированный файл рядом с программой, в эту папку import.
   В плагине запустите «Импортировать вопросы из папки сейчас» либо включите
   автоимпорт. Проверки идут через WP-Cron с выбранной периодичностью.
   Можно загрузить файл вручную: Конструктор вопросов → Импорт заданий.

Галочка «Скрыть баллы по этому вопросу в тесте» включена по умолчанию.
Картинки и аудио задаются полными http(s)-ссылками; локальные файлы не встраиваются.
Черновики .wpoq сохраняйте отдельно: экспорт не заменяет проект.

Сам редактор, инструкция и ZIP исходников не являются файлами вопросов и не
импортируются автоматически. Плагин не запускает EXE на сервере или в браузере.

Плагин автоматически размещает здесь только свои файлы редактора:
QuestionStudio.exe, README_EDITOR.txt, EDITOR_LICENSES.txt и
question-studio-source-1.0.0.zip. Ваши вопросы и черновики не изменяются.
При обновлении редактора закройте его на ПК, если сетевая папка запрещает
перезапись открытого EXE. Повторить размещение можно кнопкой в админке плагина.

Цифровой подписи нет: Windows может предупредить о неизвестном издателе.
Не отключайте антивирус ради запуска. Проекты и экспорт содержат ключи ответов —
не передавайте их участникам.

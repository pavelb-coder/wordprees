# Публикация WP Olympiad

По запросу владельца репозиторий синхронизируется после каждого завершённого обновления плагина: изменение версии и changelog → реальные тесты → установочный ZIP → проверка установки → обычный коммит/push → релиз → проверка скачивания.

## Где скачать плагин

**Постоянная ссылка на последний установочный ZIP:**

https://github.com/pavelb-coder/wordprees/releases/latest/download/wp-olympiad.zip

Все версии: https://github.com/pavelb-coder/wordprees/releases

В каждом релизе два побайтово одинаковых файла:

- `wp-olympiad-<версия>.zip` — имя с номером версии;
- `wp-olympiad.zip` — постоянное имя для ссылки `/latest/download/`.

Внутри ZIP находится папка `wp-olympiad/`. Для обновления в WordPress выберите «Плагины → Добавить плагин → Загрузить плагин» и подтвердите замену существующей версии. Не удаляйте плагин вместе с данными. Архив «Code → Download ZIP» содержит исходники репозитория и не заменяет установочный ZIP из Releases.

## Правила

- Основная ветка — `main`. История не перезаписывается. Перед отправкой проверяется актуальное состояние удалённой ветки.
- Старый `push-to-github.sh` не используется: это исторический скрипт с `--force` и жёстким локальным путём. Публикация выполняется обычными безопасными git-командами.
- Уже опубликованные теги и содержимое существующих assets не переписываются. Другой код/ZIP должен получить новую версию.
- В репозитории только исходники, документация, собственные assets редактора и учебные тестовые примеры. Настоящие вопросы, ответы, протоколы, файлы NAS, конфигурация WordPress, SQL, пароли, API-ключи и авторизация GitHub не публикуются.
- Авторизация хранится отдельно от проекта. Отзыв или истечение доступа требует нового входа; приватная конфигурация и токены не входят в исходники или ZIP.
- Синхронизация выполняется при работе над завершённым обновлением. Это не фоновый демон и не автоматическая установка плагина на рабочем сайте.

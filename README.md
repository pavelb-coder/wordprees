# WP Olympiad & Testing Master (v1.0.16)

> **Современный высокопроизводительный плагин для проведения олимпиад, экзаменов, контрольных работ и тестирования на WordPress.**
> Спроектирован по аналогии с популярным плагином [Quiz And Survey Master (QSM)](https://github.com/QuizandSurveyMaster/quiz_master_next), но с кардинальной переработкой архитектуры: устранены исторические архитектурные недостатки, в 10 раз уменьшен объём кода, внедрена серверная система Anti-Cheat и реализована академическая модель оценивания.

---

## 1. Сравнение с Quiz And Survey Master (QSM)

| Параметр | Quiz And Survey Master (QSM) | WP Olympiad & Testing Master |
|---|---|---|
| **Назначение** | Универсальные викторины / опросы общего профиля | Специализирован для **олимпиад, экзаменов, срезов знаний и тестов** |
| **Кодовая база** | ~52 600 строк PHP (легаси с 2014 г., устаревшие вызовы) | ≈ 16 900 строк современного PHP 8.1–8.4 (PSR-4, strict types), включая интерфейс администратора |
| **База данных** | 9 ненормализованных таблиц, сериализованные PHP-строки | 4 чистые реляционные таблицы с индексами и поддержкой транзакций |
| **Ошибки схемы** | Баг с отсутствующей колонкой `linked_question` на чистой установке | Идемпотентный чистый `dbDelta`, проверенный на MariaDB 11.8+ |
| **Фронтенд** | Тяжёлый jQuery, инлайн-скрипты, ~3.3 МБ в архиве | **Vanilla JavaScript (ES6+)**, 0 внешних библиотек, архив ≈ **2 МБ** вместе с Windows-редактором и его исходниками |
| **Контроль таймера** | Клиентский JS-таймер (уязвим к манипуляциям) | **Серверный таймер**: проверка `started_at` на сервере + дельта задержки |
| **Anti-Cheat защита** | Отсутствует | Контроль переключения вкладок (`blur` / `visibilitychange`), запрет копирования, авто-дисквалификация |
| **Безопасность ответов** | Часть ответов может утекать в DOM/атрибуты | **Zero-Leak API**: верные ответы и ключи физически удаляются из ответа сервера |
| **Типы оценивания** | Только базовые тесты | Академическое пропорциональное оценивание для олимпиад + штрафы за ошибку |
| **Ручная проверка (Эссе)** | Требует сторонних платных аддонов | **Встроена**: ручная проверка заданий с развёрнутым решением и рецензией |
| **Экспорт протоколов** | Платный аддон ($39) | **Встроенный экспорт в Excel / CSV** с поддержкой русской кодировки (UTF-8 BOM) |

## 2. Ключевой функционал

### 🎯 13 поддерживаемых типов заданий (включая Online Test Pad, диктанты и тренажёры):
1. **Одиночный выбор (Single Choice / Radio)** — классический выбор 1 верного ответа. Поддерживает начисление штрафных баллов за неверный ответ (механика олимпиад типа «Кенгуру»).
2. **Множественный выбор (Multiple Choice / Checkbox)** — выбор нескольких ответов с **академической формулой частичного балла**:
   $$\text{Балл} = \max\left(0, \frac{N_{\text{верных\_выбрано}} - N_{\text{ошибочных\_выбрано}}}{N_{\text{всего\_верных}}}\right) \times \text{Баллы}$$
   (Исключает получение случайных баллов при бездумном проставлении всех галочек).
3. **Выпадающий список (Dropdown)** — компактный выбор одного варианта из раскрывающегося перечня.
4. **Верно / Неверно (Boolean / True-False)** — мгновенная проверка истинности утверждения с кнопками Да/Нет.
5. **Числовой ответ (Numeric)** — ввод числа (поддерживает как точку, так и русскую запятую) с настраиваемой допустимой погрешностью ($\pm \text{tolerance}$). Например, $3{,}14 \pm 0{,}01$.
6. **Краткий текстовый ответ (Short Text) с интеллектуальной автопроверкой**:
   - **Точное совпадение (`exact`)**: сравнение с эталонными ответами и синонимами с автоматической очисткой пробелов и знаков препинания.
   - **Вхождение ключевых слов (`contains_any` / `contains_all`)**: проверка наличия любого или всех ключевых понятий в развернутой формулировке ответа с поддержкой русской грамматики и словоформ (склонение/падежи).
   - **Нечёткое сопоставление с допуском опечаток (`fuzzy`)**: многобайтовый алгоритм расстояния Левенштейна (UTF-8 / кириллица) — ответ принимается при 1–3 допустимых опечатках (например, «Масква» засчитывается как «Москва»).
   - **Регулярные выражения (`regex`)**: строгая валидация сложных форматов и шаблонов.
   - **Опции нормализации**: игнорирование регистра, отсечение кавычек и знаков препинания, схлопывание пробелов.
7. **Установление соответствий (Matching как в Online Test Pad)** — сопоставление терминов левой колонки с определениями правой колонки с пропорциональным частичным начислением баллов.
8. **Установление последовательности (Ordering / Sequence как в Online Test Pad)** — расстановка элементов в правильном хронологическом или логическом порядке с кнопками перемещения ▲/▼ и расчётом совпадений позиций.
9. **Заполнение пропусков в тексте (Fill in the Blanks с вариантами ответов как в Online Test Pad)**:
   - **3 режима выбора ответов (`choice_mode`)**:
     1. **Инлайн-выпадающий список (`dropdown`)**: компактный выпадающий селектор непосредственно внутри строки текста в каждом пропуске.
     2. **Интерактивный банк слов / вариантов (`word_bank`)**: кликабельные фишки/чипы под текстом с возможностью вставки в слоты по клику или автозаполнению первого свободного пропуска, визуальным статусом использования, очисткой по крестику или повторному клику, и кнопкой «Сбросить все».
     3. **Классический ручной ввод (`input`)**: текстовые инлайн-поля для ручного набора с клавиатуры (с поддержкой синонимов и регистронезависимости).
   - **Удобный синтаксис шаблона**: `{=правильно|вариант2|вариант3}` (знак `=` или `*` обозначает верный ответ) либо классический `{верный_ответ|синоним}`.
   - **Дистракторы (ложные варианты)**: дополнительное поле дистракторов через запятую для усложнения банка слов или списков вариантов.
   - **Zero-Leak Anti-Cheat**: сервер перемешивает варианты выбора и полностью вырезает маркеры верных ответов перед передачей клиенту, гарантируя невозможность подсмотреть ответ в коде страницы или инструментах разработчика.
   - **Пропорциональное оценивание**: точный расчёт набранных баллов по числу верно заполненных пропусков.
10. **Шкала / Ползунок (Slider / Rating Scale как в Online Test Pad)** — выбор числового значения на шкале с гибким шагом, бейджем текущего значения и диапазоном допуска.
11. **Развёрнутое решение / Эссе (Essay) с автоматической проверкой ключевых понятий**:
   - Автоматическое сканирование текста на наличие обязательных терминов и формулировок с учётом падежей и окончаний.
   - Конфигурируемый порог минимального числа терминов и минимального объёма текста (слов).
   - Два режима начисления баллов: **пропорциональный** (по числу встретившихся терминов) и **«всё или ничего»**.
   - Режимы финализации: полная авто-проверка (`auto_pass`) либо передача на утверждение жюри с предзаполненным баллом и детализацией.
   - **Помощник проверки жюри**: кнопки «⚡ Автопроверить ответ» и «⚡ Автопроверить все текстовые ответы» в протоколе проверки попытки.
12. **Составление слова из букв (Word Scramble / Анаграмма)** — интерактивный конструктор слов из перемешанных буквенных плиток (фишек):
   - Участник нажимает на плитки с буквами или вводит их с клавиатуры для сборки целевого слова в слоты ответа.
   - Поддержка удаления букв по клику на заполненный слот, клавишей `Backspace` или кнопкой сброса.
   - Поддержка дополнительных («лишних») букв-дистракторов для усложнения задания.
   - Полная **Anti-Cheat защита**: целевое слово физически не передаётся на клиент (в DOM передаются только перемешанные плитки с буквами и длина слова).
   - Поддержка синонимов, автоматической проверки и рецензирования жюри.
13. **Интерактивный диктант (Interactive Dictation / Орфограммы и пунктограммы)** — академический формат для олимпиад по русскому и иностранным языкам (по аналогии с «Тотальным диктантом» и Грамота.ру):
   - Цельный связный текст с интерактивными инлайн-селекторами на месте орфограмм и знаков препинания.
   - Удобный синтаксис разметки: `{=верно|ошибка1|ошибка2}` (например: `Шёл {=дождь|дожть}. Мы шли по алле{=е|и}, любуясь пр{=и|е}родой{=,|нет знака} которую мы любим.`).
   - **Встроенное аудирование**: опциональный HTML5-аудиоплеер для прослушивания диктовки текста (`audio_url`).
   - Настраиваемое оценивание: **пропорциональное** (по доле верно решённых мест) или **«всё или ничего»**, а также допустимое число ошибок без снижения балла (`allowed_mistakes`).
   - **Zero-Leak Anti-Cheat**: варианты выбора перемешиваются на сервере, правильный ответ не утекает в HTML/JS.
14. **Иллюстрации к вопросам и форматирование текста (Rich Media & Typography)**:
   - **Загрузка и прикрепление изображений**:
     - Прямая интеграция с нативной **Медиатекой WordPress (`wp.media`)** — выбор или загрузка файлов с компьютера в один клик.
     - Возможность указания внешнего URL изображения (`image_url`).
     - Подпись к рисунку (`image_caption`) и альтернативный текст (`image_alt`).
     - Выбор расположения иллюстрации: **над текстом задания** (`above`) или **под текстом задания** (`below`).
     - Мгновенный предпросмотр миниатюры и кнопка быстрого удаления в карточке вопроса в админке.
     - **Полноэкранный Lightbox на фронтенде**: при клике на изображение открывается модальное окно с увеличенной картинкой высокого разрешения (закрывается по клику или клавишей `Escape`).
   - **Панель инструментов форматирования текста (Formatting Toolbar)**:
     - Расположена прямо над полями формулировки задания (`title`) и подробного описания (`content`).
     - Кнопки быстрого форматирования:
       - **Жирный** (`<strong>`), *Курсив* (`<em>`), <u>Подчёркнутый</u> (`<u>`), <s>Зачёркнутый</s> (`<s>`).
       - 🖍️ **Выделение маркером** (`<mark>`).
       - **Степени и формулы**: верхний индекс `x²` (`<sup>`), нижний индекс `x₂` (`<sub>`).
       - **Программный код и формулы**: инлайн-код `</>` (`<code>`), блоки кода `{ }` (`<pre><code>`).
       - **Цитаты и врезки**: `❝` (`<blockquote>`).
       - **Списки**: маркированный `•` (`<ul><li>`), нумерованный `1.` (`<ol><li>`).
       - **Ссылки и инлайн-картинки**: кнопка вставки гиперссылки `🔗` и картинки в текст `🖼️`.
       - **👁️ Живой предпросмотр**: переключение между режимом ввода и просмотром отрендеренного оформления.
   - **Академическая безопасность**: текст проходит санитизацию через `wp_kses_post()`, отсекая уязвимости (XSS/скрипты), сохраняя все необходимые теги оформления, формул, списков и таблиц.
15. **Обязательные вопросы и контроль перемешивания вариантов ответов**:
   - **Обязательные задания (`is_required`)**:
     - В карточке задания доступен чекбокс **«* Обязательный вопрос»** со звёздочкой в заголовке карточки.
     - На фронтенде обязательный вопрос визуально выделяется красной звёздочкой `*` и бейджем **«ОБЯЗАТЕЛЬНЫЙ»**.
     - Неотвеченные обязательные задания помечаются красным индикатором в полосе навигации по вопросам.
     - **Двухуровневый контроль сдачи**:
       1. *Клиентский*: при попытке нажать «Завершить олимпиаду» без ответов на обязательные задания участник получает предупреждение со списком номеров неотвеченных заданий и автоматически перемещается к первому из них.
       2. *Серверный*: эндпоинт `POST /submit` в REST API валидирует наличие непустого ответа на каждый обязательный вопрос и возвращает ошибку 400 (`required_question_missing`), исключая возможность отправки пустых ответов в обход интерфейса.
   - **Индивидуальный контроль перемешивания вариантов (`shuffle_answers`)**:
     - В каждом задании доступен чекбокс **«🔀 Перемешивать варианты ответов»**.
     - Позволяет выборочно отключать перемешивание для конкретных заданий, где принципиален исходный авторский порядок вариантов (например: «Все вышеперечисленные», «Ни один из вариантов», «Варианты А и Б», хронологические последовательности, шкалы интенсивности).
     - Поддерживается для одиночного/множественного выбора, выпадающих списков, сопоставлений и банка слов.
16. **Группировка вопросов по разделам и скрытие баллов во время тестирования**:
   - **Группировка вопросов по разделам / частям (`group_name`)**:
     - В каждом задании доступно поле **«Раздел / Группа»** с автодополнением (datalist) из названий уже созданных в олимпиаде разделов (например, *«Часть 1: Теория»*, *«Часть 2: Практические задачи»*, *«Модуль 3: Аудирование»*).
     - В конструкторе заданий админ-панели доступна панель фильтрации по разделам (**«Все задания»**, **«Раздел 1»**, **«Раздел 2»** и т.д.) для быстрой работы с крупными тестами на десятки вопросов.
     - В карточке вопроса выводится синий бейдж раздела `📁 [Название раздела]`.
     - На фронтенде тестирования:
       - Над вопросом отображается элегантный бейдж текущего раздела `📁 [Раздел]`.
       - Полоса быстрой навигации по вопросам структурируется по блокам разделов с заголовками, обеспечивая чёткое ориентирование участника по частям олимпиады.
   - **Скрытие баллов за задания во время тестирования (`show_question_points`)**:
     - **Сохранённый общий режим** `show_question_points` продолжает учитываться. Общий тумблер удалён из формы в 1.0.4; сохранение других полей не меняет прежнее значение. Видимость баллов отдельного задания по-прежнему задаётся в его карточке.
     - **Индивидуальная настройка вопроса**: в каждом задании предусмотрен чекбокс **«🙈 Скрыть баллы за этот вопрос в тесте»** (`show_points`). Позволяет выборочно скрыть или открыть баллы за конкретные вопросы независимо от глобальной настройки олимпиады. **У новых вопросов галочка включена по умолчанию** — баллы за только что созданное задание сразу скрыты от участников; в шапке карточки вопроса состояние видно по значку 🙈 рядом с весом задания.
17. **Общий текст к вопросам (пассажи, кейсы, условия, фрагменты для чтения)**:
   - **Единый текст для серии заданий**:
     - Реализована полноценная поддержка привязки одного общего контекстного блока (отрывка литературного произведения, исторического документа, описания физического эксперимента, бизнес-кейса или условия комплексной задачи) к серии вопросов олимпиады (например, к заданиям 1–4).
   - **Интерактивный менеджер общих текстов**:
     - В верхней панели конструктора заданий доступна кнопка **«📖 Общие тексты к заданиям (N)»**.
     - Модальное окно с боковой панелью всех созданных текстов и счётчиком привязок (например, *«Используется в 3 задан.»*).
     - Редактор с панелью форматирования (жирный, курсив, подчёркивание, маркер, цитаты-врезки, списки, ссылки, картинки) и живым предпросмотром.
     - Быстрое назначение: чекбоксы со списком вопросов позволяют привязать текст сразу к нужной группе заданий в один клик.
   - **Управление прямо в карточке задания**:
     - В блоке настроек каждого вопроса доступно поле выбора общего текста, кнопка быстрого просмотра содержимого `👁️ Просмотр`, переход в менеджер и создание нового текста на лету.
     - В шапке карточки вопроса отображается янтарный бейдж `📖 [Название текста]`.
   - **Эргономичный интерфейс участника на фронтенде**:
     - Над формулировкой вопроса выводится стилизованный ридер-блок **«📖 ОБЩИЙ ТЕКСТ К ЗАДАНИЯМ: [Название]»**.
     - Участник может свернуть блок (**«Свернуть ▴»**) для удобного ответа на компактных экранах и развернуть обратно (**«Развернуть ▾»**).
     - Состояние сворачивания сохраняется при переходах между вопросами этого контекста.
18. **Исключительно русскоязычные экспортные файлы по папкам**:
   - При экспорте в локальную или сетевую папку (SMB/Windows Share, NFS, FTP, WebDAV), а также при скачивании архива, файлы организуются исключительно по русскоязычным каталогам:
     - `протоколы/` — один основной CSV `протокол_[имя].csv` на каждую выгрузку олимпиады; он содержит все ответы и оценки участников.
     - `вопросы/` — с 1.0.16 ни одна выгрузка здесь ничего не создаёт: экспорт вопросов удалён, а ранее выгруженные файлы снимаются точечно (см. «Снятие папки `вопросы/` с 1.0.16»).
     - `попытки/` — детальные индивидуальные протоколы участников с разбором решений (`попытка_[id]_[фио].csv`).
   - **Удаление нерусифицированных и лишних файлов**:
     - Из выгрузки полностью исключены англоязычные дубликаты папок (`protocols/`, `questions/`, `reports/`, `attempts/`), оставлены только русские названия.

### 📊 Возможности анализа ответов (по аналогии с Online Test Pad):
* **Сводная матрица ответов (Pivot Matrix / «Сводные данные»)**:
  - Полная интерактивная матрица: строки — участники, столбцы — вопросы олимпиады ($Q_1, Q_2, \dots, Q_n$).
  - Цветовая индикация результатов: зелёный (верно), жёлтый (частичный балл), красный (неверно/штраф), синий (на проверке).
  - Наведение курсора / всплывающая подсказка с точным отформатированным ответом участника и набранными баллами.
  - Нижняя сводная строка с итоговым процентом решаемости и средним баллом за каждый вопрос.
* **Экспорт матрицы в Excel / CSV**: скачивание полной таблицы со всеми ответами и оценками каждого участника по каждому заданию в один клик с кодировкой UTF-8 BOM.
* **Психометрический анализ заданий (Item Response Analysis)**:
  - **Индекс трудности ($P$-value)**: процент решаемости каждого вопроса с цветовым статусом (Оптимальная, Трудный, Лёгкий).
  - **Индекс дискриминативности ($D$-index по методу крайних групп Келли 27%)**: способность вопроса отличать подготовленных участников (топ 27%) от слабо подготовленных (нижние 27%). Автоматическое выявление дефектных заданий с отрицательной дискриминацией ($D < 0$).
* **Анализ дистракторов и частотное распределение**:
  - Графические диаграммы долей выборов каждого варианта ответа ($A, B, C, D$) с выделением правильного ключа.
  - Выявление неработающих дистракторов и «вопросов-ловушек».
  - Частотный словарь самых популярных ответов для открытых вопросов.
* **Гистограмма и психометрика результатов (Score Distribution)**:
  - Гистограмма распределения участников по 5 диапазонам баллов: 0–20%, 21–40%, 41–60%, 61–80%, 81–100%.
  - Расчёт статистических характеристик генеральной совокупности: Среднее арифметическое (Mean), Медиана (Median), Стандартное отклонение ($\sigma$), размах (Min - Max), процент успешной сдачи (Pass Rate).

### ⚖️ Баллы за каждый пункт ответов (целочисленное дифференцированное оценивание):
В дополнение к стандартной балльной шкале за весь вопрос, плагин позволяет назначать **персональные целые баллы за каждый вариант ответа, пару соответствия или элемент последовательности**:
* **Одиночный выбор и выпадающие списки (`single`, `dropdown`)**: возможность задавать различные целые баллы в зависимости от качества выбранного ответа (например: вариант A — 3 б. за полное обоснованное решение, вариант B — 1 б. за частичный ответ, вариант C — 0 б.).
* **Множественный выбор (`multi`)**: суммирование баллов всех отмеченных участником вариантов. Поддерживаются положительные, нулевые и отрицательные (штрафные) целые веса вариантов (например, выбор правильных вариантов даёт +2 и +1 б., а выбор ловушки-дистрактора вычитает -1 б.).
* **Сопоставление (`matching`)**: начисление индивидуального целого балла за каждую верно сопоставленную пару понятий.
* **Упорядочивание (`ordering`)**: начисление индивидуального целого балла за каждый элемент, поставленный на верную позицию.
* **Строго целочисленная модель (Integer Points)**: все баллы за задания, штрафы, начисленные очки и итоговые суммы хранятся и отображаются в виде **целых чисел** (без десятичных дробей `.00` / `.5`), обеспечивая классический формат школьных и вузовских олимпиад.
* **Автоматический расчёт максимального балла**: при сохранении вопроса система автоматически определяет и фиксирует максимальный достижимый балл вопроса на основе суммы весов вариантов.
* **Zero-Leak безопасность**: индивидуальные баллы за варианты ответов хранятся на сервере и **никогда не передаются** в клиентский интерфейс тестируемого до момента завершения проверки, что исключает возможность угадывания правильных ответов через инспектор кода.

### 🔒 Гибкие режимы завершения и отключение показа результатов в конце:
В настройках олимпиады можно выбрать один из 5 режимов показа результатов участнику:
1. **Сразу показать всё (`immediate`)** — отображаются набранные баллы, процент, статус зачёта, итоговая степень, разбор каждого задания, правильные ответы и пояснения авторов (режим для тренировочных тестов).
2. **Только итоговый балл (`score_only`)** — участник видит свои набранные баллы и процент, но правильные ответы и разбор ошибок скрыты (защита от утечки решений).
3. **После окончания тура (`after_end`)** — результаты и правильные ответы открываются только после наступления даты окончания олимпиады (`end_time`).
4. **Ручная проверка жюри (`manual`)** — баллы отображаются только после завершения ручной оценки открытых заданий/эссе членами жюри.
5. **🚫 Полное отключение показа результатов в конце (`none`)**:
   - При завершении тестирования баллы, процент, ошибки и правильные ответы **полностью скрыты от участника**;
   - На сервере в REST API ключи и оценки отфильтровываются, исключая утечку через DevTools / Network tab;
   - Участник видит аккуратный финальный экран с подтверждением успешной сдачи и **кастомным сообщением от организаторов** (например: *«Спасибо за участие! Ваши ответы сохранены и переданы в оргкомитет. Протоколы будут опубликованы на официальном сайте»*);
   - Жюри и организаторы при этом видят все баллы, детальные ответы и сводные результаты в административной панели и протоколах.

### 🛡️ Система честной игры и Anti-Cheat:
* **Серверный таймер**: клиент не может «заморозить» таймер через DevTools или подмену времени ОС. Время старта и сдачи фиксируются сервером.
* **Фиксация ухода со страницы**: отслеживание переключения вкладок браузера (`visibilitychange` и `window.blur`). Количество переключений заносится в официальный протокол. При превышении заданного лимита попытка автоматически дисквалифицируется.
* **Защита от копирования**: опциональный запрет контекстного меню, копирования текста и выделения.
* **Рандомизация**: перемешивание порядка заданий и вариантов ответов для каждого участника.
* **Лимит попыток**: 1 попытка для официальных туров олимпиад либо $N$ попыток для тренировочных тестов.
* **Временное окно олимпиады**: возможность задать дату/время начала и окончания (до старта вход закрыт, после окончания приём ответов блокируется).

### 📥 Экспорт официальных протоколов (с вопросами и ответами участников):
* **Экспорт всех результатов с вопросами и ответами пользователей (Excel / CSV)**:
  - Формирует официальный протокол олимпиады в кодировке UTF-8 с BOM (корректно открывается в Microsoft Excel без кракозябр).

  - Детальная построчная таблица по каждому заданию: номер, формулировка, тип вопроса, ответ участника, правильный ответ/авторское пояснение, начисленный балл, макс. балл, вердикт (Верно / Частично / Неверно / На проверке) и рецензия жюри.

* **Одиночное удаление попытки (Row Action)**:

### ⏱️ Фоновый импорт вопросов — без входа в «Вопросы» (1.0.1)

Включите **«Автоматически импортировать задания из сетевой папки»** и выберите **«Каждую минуту»** в настройках олимпиады → **«Подключение к сетевой папке»**, затем сохраните. После изменения файла на хранилище **не требуется открывать конструктор и обновлять страницу**.

- Планировщик регистрируется на всех запросах WordPress. Неправильное старое расписание, отложенное на много часов событие и дубликаты автоматически исправляются; минутный интервал `wpo_olympiad_minute` не конфликтует с чужим `every_minute`.
- Если встроенный запуск WP-Cron не сработал, резервная проверка выполняется при обычных PHP-запросах к сайту, в том числе через **штатный heartbeat любой страницы админки**. Проверка запускается после формирования основного ответа (shutdown); на PHP-FPM ответ отправляется до сетевого чтения. Общая блокировка и минутный throttle не позволяют каждому посетителю запускать полный импорт заново.
- Обрабатываются **все олимпиады**, а не только последние 100. Работа делится на ограниченные пакеты с курсором и продолжением; копирование Windows-редактора вынесено после проверок вопросов и пропускается до завершения ожидающих пакетов. Медленное хранилище редактора не стоит перед импортом вопросов.
- Блокировки отдельной олимпиады, повторное чтение свежего хэша и проверка владельца перед записью защищают от пересекающихся штатных ручных/фоновых запусков и запоздавших процессов. Обычный ручной повтор неизменённого файла также не дублирует вопросы; если список вопросов очищен полностью, его можно восстановить из того же файла. Явный внутренний `force=true` оставлен для намеренного повторного импорта.
- **«Последняя проверка» отделена от «Последнего импорта»**: фиксируются также неизменённый файл и ошибка, источник запуска и сообщение. Интервал отсчитывается от начала проверки, не от её завершения. Неудачное чтение не меняет хэш успешно импортированного файла и не удаляет имеющиеся вопросы.
- Блок **«Фоновая синхронизация»** в настройках и конструкторе показывает живой статус, число вопросов, последнюю/следующую проверку и источник. AJAX защищён `manage_options` и nonce; heartbeat не раскрывает статус подписчикам. Пароли сетевой папки и API-ключи не возвращаются.
- В открытом конструкторе чистый список обновляется автоматически. **Несохранённые правки, активное редактирование и открытые окна блокируют автоматическую перезагрузку**; есть уведомление и явное подтверждение обновления. Настройки подключения никогда не перезагружаются таким образом.
- Для новых олимпиад по умолчанию выбрана минута; существующие явные `hourly`, `twicedaily`, `daily` сохранены. Старые `always`, `minute`, `1min` поддерживаются как минутная проверка без привязки к конструктору.

**Если сайт совсем без посетителей:** PHP не работает по часам сам по себе. Для действительно фоновой работы без обращений настройте в панели хостинга или доверенном внешнем планировщике **HTTP(S) GET раз в минуту** к адресу `https://ваш-сайт/путь-WordPress/wp-cron.php`. Готовая ссылка и кнопка копирования находятся в том же блоке синхронизации. Это штатный планировщик WordPress, а не новый анонимный API импорта. **Не добавляйте `doing_wp_cron=1`**. При отсутствии доступа к хостингу передайте ссылку его администратору. Запрос должен достигать PHP, а не кеша/страницы авторизации; полностью закешированные визиты тоже не запускают плагин. Сетевые ошибки, очередь, длительное чтение и лимиты PHP могут увеличивать фактическую задержку — это не жёсткий real-time таймер.

Подробный порядок обновления: **`UPDATE.md`**. Проверки исправления: **`tests/NETWORK_SYNC_QA.md`**.

**Автоматическое размещение — без отдельной обязательной кнопки:** при сохранении новой / существующей сетевой конфигурации, успешной проверке подключения, ручном сетевом импорте и сетевом экспорте плагин размещает программу в сетевой папке. Фоновый минутный воркер WP-Cron делает это и для уже подключённых олимпиад, **в том числе при выключенном автоимпорте вопросов** или отложенной проверке файла заданий.

```text
<подключённая сетевая папка>/import/
├── QuestionStudio.exe

```

Если подключённый путь уже заканчивается на `import`, второй `import/import` не создаётся. Поддерживаются локальная / примонтированная папка, UNC/SMB, FTP/FTPS и WebDAV. В сетевую папку **не выкладываются примеры вопросов** и не распаковывается архив исходников; EXE, TXT, ZIP и `.wpoq` не попадают в автоматический поиск файлов заданий. Полный Windows ZIP, инструкция и лицензии хранятся отдельно в плагине для скачивания; новые размещения не создают эти файлы в сетевой папке. Ранее размещённые копии автоматически не удаляются.

**Сохранность и статус:** редактор обновляет только два своих именованных файла. Остальные существующие файлы в `import/`, в том числе инструкции, шаблоны, вопросы, проекты и пользовательские папки, не удаляются. На локальном / примонтированном диске неизменённые файлы не перезаписываются; отсутствующие или повреждённые восстанавливаются при следующей проверке. Удалённое успешное размещение кешируется, чтобы не передавать EXE каждую минуту; повторная проверка подключения или дополнительная кнопка **«Обновить редактор в import»** повторяют передачу, а новый комплект инвалидирует кеш. Есть защита от параллельного запуска, повтор после ошибки не чаще раза в минуту и отдельный статус программы: доступность папки не скрывает ошибку копирования EXE. Локальная запись атомарная; частичный сбой WebDAV/FTP/SMB не считается успешной установкой.

**Как пользоваться после обновления плагина:**
1. Откройте настройки олимпиады → «Подключение к сетевой папке», укажите папку и сохраните настройки либо проверьте доступ. Программа появится в `import/` автоматически.
2. Откройте `QuestionStudio.exe` на Windows-ПК (или скачайте из админки); создайте вопросы и сохраните `.wpoq` для дальнейшего редактирования.
3. Выберите «Экспорт → Excel / CSV / JSON» и сохраните полученный файл в `import/` сетевой папки.
4. Импортируйте файл кнопкой «Импортировать вопросы из папки сейчас» / через конструктор либо включите автоимпорт, при необходимости с периодичностью «Каждую минуту».

Для фоновой работы нужен действующий WP-Cron: без посещений сайта задания выполняются при следующем визите; для строгой минутной периодичности настройте системный cron. На сетевом хранилище нужны права записи; для прямого SMB из Linux — `smbclient` или монтирование шары. При HTTPS WebDAV сертификат должен быть доверенным серверу WordPress. Если запуск EXE с сети ограничен, скопируйте его на ПК и уточните правила у администратора. **Цифровой подписи нет**, Windows может предупредить о неизвестном издателе; не отключайте антивирус. Файлы проектов и экспорта содержат ключи ответов: доступ к сетевой папке должен быть только у организаторов, а размещение в публичном каталоге uploads само по себе не защищает эти данные.

### 📁 Подключение к сетевой папке:
* **Универсальные типы подключения к сетевым хранилищам**:
  - **Автоматический путь по умолчанию**: если путь не задан, выгрузка сохраняется в надёжную директорию `wp-content/uploads/olympiad_network_share` с гарантированными правами на запись.
  - **Локальный путь / Примонтированная сетевая папка**: поддержка смонтированных папок ОС (NFS, CIFS/Samba, Windows Share `\\host\share`, внешние диски, локальные NAS-шары).
  - **Корректная обработка путей**: поддержка экранирования Windows UNC-путей, относительных путей, символа домашней директории `~/`, автоматическое создание поддиректорий (`wp_mkdir_p`).
  - **SMB / Windows Share (прямое подключение без монтирования)**: поддержка сетевых папок Windows вида `\\10.200.10.10\kvant\` и `smb://10.200.10.10/kvant/` напрямую из Linux через интеграцию с `smbclient` с авторизацией (пользователь, пароль, домен) без необходимости ручной настройки монтирования в ОС. Также поддерживаются примонтированные папки (`/mnt/share`).
  - **WebDAV / Облачные диски (HTTP / HTTPS)**: прямая отправка файлов по протоколу WebDAV (Nextcloud, ownCloud, Synology, QNAP) с HTTP Basic Authentication.
  - **FTP / FTPS серверы**: выгрузка на локальные сетевые FTP-серверы с поддержкой пассивного режима и защищённой авторизации.
* **Прямая выгрузка файлов без архивации (немедленный доступ)**:
  - Выгрузка проводится **напрямую в виде файлов**, без создания ZIP-архивов и без паролей.
  - Члены жюри и учителя могут сразу открыть свежий CSV-протокол двойным кликом в Microsoft Excel прямо из общей папки.
* **Полный комплект официальной документации внутри папки**:
  1. `протоколы/протокол_[имя].csv` — единственный новый основной протокол олимпиады со всеми ответами и оценками (UTF-8 BOM для Microsoft Excel). При повторной выгрузке этот файл обновляется.
  2. `вопросы/` — с 1.0.16 не создаётся: экспорт заданий из плагина удалён, папка освобождается от прежних файлов выгрузки.
  3. `попытки/` — индивидуальные работы. Папка `отчёты/` в новой выгрузке и ZIP не создаётся; три её старых файла снимаются после успешной выгрузки, а если транспорт не может подтвердить безопасность удаления, папка и файлы просто остаются на месте и в подтвердении появляется предупреждение, а не ошибка (1.0.15).
  4. Старые `сводный_протокол.csv`, `ответы_участников.csv` и датированные копии не создаются, но уже существующие не удаляются. При нескольких олимпиадах в одной папке может быть несколько основных протоколов.
* **Автоматическая выгрузка при каждой сдаче (Auto-Export)**:
  - Опция непрерывной репликации: при каждой отправке теста участником плагин обновляет файлы протоколов и индивидуальных попыток в сетевой папке в фоновом режиме.
  - **С 1.0.16 папка `вопросы/` не создаётся ни одной выгрузкой** (решение владельца): удалены кнопка «Экспортировать вопросы в сетевую папку», файлы заданий в ручной полной выгрузке и в скачиваемом ZIP, а также URL скачивания `wpo_action=export_questions` в админке. Новых настроек не добавлено.
  - Ранее созданные файлы `вопросы/` **снимаются точечно после ближайшей успешной выгрузки** — теми же правилами, что и `отчёты/`: семь конкретных имён (`вопросы_<имя>.csv|.json`, `критерии_и_ответы_<имя>.csv`, `список_заданий.csv`, `правильные_ответы.csv`, устаревшие `questions.csv|.json`), без масок и рекурсии, пустая папка убирается, чужие файлы не трогаются. Если транспорт не подтверждает безопасность, файлы остаются, а выгрузка считается успешной с предупреждением.
  - Запись основного протокола, размещение редактора в `import/` и снятие трёх старых файлов `отчёты/` работают как раньше; непроверяемая очистка отчётов с 1.0.15 показывает предупреждение и не считает выгрузку неудачной.
* **Excel-шаблон для вопросов**:
  - Шаблон XLSX можно скачать в конструкторе вопросов; его автоматическое и кнопочное размещение в `import/` отключено.
  - Пользователь может сам положить заполненный XLSX в `import/`; импорт XLSX/XLSM/CSV/JSON, проверка файлов и автоимпорт сохраняются.
  - Если подключённый путь уже заканчивается на `import`, вложенный `import/import` не создаётся. Старые ссылки CSV/JSON/XLSM на образцы возвращают HTTP 410.
  - Ранее созданные шаблоны, инструкции, вопросы, проекты и ответы не удаляются. Ненужные копии можно удалить вручную после проверки содержимого.

* **Экспорт заданий олимпиады (Questions Export) — удалён в 1.0.16**:
  - Из настроек олимпиады убрана кнопка «📤 Экспортировать вопросы в сетевую папку» и её обработчик в `admin/js/admin.js`; прямой URL `wpo_action=export_questions` (скачивание CSV/JSON в админке) отвечает **HTTP 410** с пояснением вместо файла.
  - Ручная полная выгрузка «📁 В сетевую папку» (страница «Результаты» или AJAX) и «📦 Скачать комплект файлов (ZIP)» содержат только `протоколы/` и `попытки/` — пять файлов заданий из комплекта исключены.
  - `NetworkExport::export_questions_to_network()` и AJAX-действие `wp_olympiad_export_questions_to_network` сохранены и помечены `@deprecated`: внешние интеграции продолжают работать, но точки входа в интерфейсе нет. Импорт заданий (XLSX/CSV/JSON), автоимпорт и размещение редактора в `import/` не затронуты.
  - **Надёжная проверка подключения (Zero-Placeholder Bug)**: устранена ошибка, при которой текстовый плейсхолдер поля пути воспринимался как адрес сетевого сервера; при пустом поле плагин автоматически подключается к локальной сетевой папке хранилища по умолчанию.

* **Автоматический импорт вопросов из сетевой папки (Network Auto-Import)**:
  - **Постоянная синхронизация заданий**: возможность активировать автоимпорт вопросов из сетевой папки (`network_auto_import`) в разделе «Подключение к сетевой папке».
  - **Интеллектуальный контроль изменений (MD5 Hash-контроль)**: плагин вычисляет хэш содержимого файла заданий и выполняет синхронизацию только при фактическом изменении файла на сетевом диске, исключая повторные лишние перезаписи и дублирование вопросов.
  - **Гибкие режимы импорта**:
    - **Добавление (`append`)**: новые вопросы из сетевого файла добавляются в конец текущего списка заданий;
    - **Замена (`replace`)**: старый список вопросов олимпиады полностью очищается и заменяется актуальными заданиями из файла сетевой папки.
  - **Настраиваемая периодичность**:
    - **Каждую минуту (`every_minute` / 60 сек)**: фоновая проверка через WP-Cron и резервный watchdog запросов / heartbeat; для полностью неактивного сайта нужен внешний планировщик;
    - Фоновое расписание WP-Cron: каждый час (`hourly`), дважды в день (`twicedaily`), раз в день (`daily`);
    - Старый режим `always` совместим с минутной проверкой и больше не зависит от входа в конструктор. Явное сохранение сетевых настроек по-прежнему проверяет подключение сразу.
  - **Автопоиск файлов или точное имя**: сначала проверяется непосредственно `import/` на `.xlsx`, `.xlsm`, `.csv`, `.json` и `.tsv`. Если там нет файлов поддерживаемых форматов, сохраняется прежний резервный поиск: корень и до трёх уровней подпапок локального/смонтированного диска либо корень FTP/FTPS, SMB или WebDAV. Если путь уже указывает на `import/`, используется сама эта папка без `import/import`.
  - **Приоритет и безопасность выбора**: внутри выбранного расположения сначала идут обычные файлы и стандартные имена (`questions.csv`, `questions.xlsx`, `import.csv` и т. д.), затем файлы с именами образцов/шаблонов. Проверка и автоимпорт перебирают их до первого файла с заданиями. Если подходящие по расширению файлы есть в `import/`, но ни один не распознаётся, выводится ошибка; к другому каталогу автоматически не переходят. Если сервер сообщает об ошибке доступа к `import/`, резервный поиск не запускается.
  - **Закрепление источника**: простое имя `questions.csv` сначала ищется в `import/`, затем по прежнему пути; для точного выбора используйте `import/questions.csv` либо `./questions.csv` для корня хранилища. Если подключённый путь уже `import/`, укажите только имя. Файлы по явно указанному относительному пути не подменяются одноимёнными из другой папки.
  - **Внимание к старым файлам**: сохранённые ранее образцы и задания в сетевой `import/` могут стать источником автоимпорта. Проверьте их или укажите точный путь, особенно если выбран режим **«Заменять»**, который изменяет существующие вопросы. Плагин не удаляет эти файлы.
  - **Кнопка ручного запуска «📥 Импортировать вопросы из папки сейчас» (AJAX)**: позволяет администратору моментально запустить синхронизацию прямо из раздела настроек сетевой папки с выводом статуса, количества импортированных заданий и имени файла.
  - **Информационный аудит-блок**: отображает дату и время последнего импорта, имя файла, число загруженных заданий, режим и статус выполнения.

## 3. Архитектура и оптимизация кода

### Схема базы данных (4 таблицы):
1. `wp_olympiad_quizzes` — метаданные олимпиады, регламент, даты, параметры оценивания и античита.
2. `wp_olympiad_questions` — задания с типами, весами баллов, штрафами и решениями. Индекс `(quiz_id, sort_order)`.
3. `wp_olympiad_attempts` — сессии прохождения: токен сессии, ФИО участника, email, телефон (`participant_phone`), город (`participant_city`), школа/класс (`participant_org`), баллы, время, статус, счетчик вкладок. Индекс `(quiz_id, status, score, duration_seconds)`.
4. `wp_olympiad_responses` — индивидуальные ответы на каждое задание, начисленный балл и комментарий жюри.

### Оптимизации и применение WordPress API:
* **Пакетная вставка (Batch Insert)**: сохранение всех ответов тестирования в `Grader::save_responses` выполняется за **один SQL-запрос** вместо $N$ последовательных запросов.
* **Транзакции БД (ACID)**: фиксация результата и ответов обёрнута в `START TRANSACTION ... COMMIT`, исключая повреждение данных при сетевом сбое.
* **In-Memory кэширование**: статический runtime-кэш сущностей `Quiz`, `Question` и списков вопросов устраняет дублирующие SQL-запросы внутри одного жизненного цикла PHP.
* **Корректное использование WordPress APIs**:
  - `dbDelta()` с соблюдением стандартов двух пробелов у `PRIMARY KEY` и индексов.
  - Строгая валидация прав доступа (`current_user_can('manage_options')`) и проверка nonce (`check_ajax_referer`, `check_admin_referer`).
  - Полная санитизация входных данных (`sanitize_text_field`, `sanitize_key`, `sanitize_email`, `wp_kses_post`) и экранирование вывода (`esc_html`, `esc_attr`, `esc_url`, `esc_textarea`).
  - Неблокирующие асинхронные вебхуки через `wp_remote_post(..., ['blocking' => false])`.
  - Email-уведомления об итогах и сдачах отключены с 1.0.3, в том числе для старых олимпиад. Системные письма самого WordPress не блокируются.
  - Регистрация REST-маршрутов с обязательными `permission_callback`.
* **Нулевой оверхед на фронтенде**: чистый Vanilla JavaScript без сторонних фреймворков и библиотек. Общий размер стилей и скрипта — менее **40 КБ**.

## 4. Шорткоды и внешнее подключение

### Вставка на страницах WordPress:
| Шорткод | Описание | Пример |
|---|---|---|
| `[wp_olympiad id="X"]` | Вставка интерактивного тестирования / олимпиады на любую страницу | `[wp_olympiad id="1"]` |
| `[wp_olympiad_my_results]` | Личный кабинет: история прохождения тестов текущим пользователем | `[wp_olympiad_my_results]` |

### 🔗 Внешнее подключение и интеграция (External Connection):
Карточка **«🔗 Внешнее подключение и интеграция»** в редакторе олимпиады объединяет каналы запуска и обмена данными со сторонними системами.

1. **Прямая ссылка для участников (Direct Link)**:
   ```text
   https://ваш-сайт.ру/?wpo_runner=56
   ```
   Открывает олимпиаду в чистом полноэкранном виде (без шапки, подвала и сайдбаров темы оформления). Идеально для отправки участникам в Telegram-каналы, VK, мессенджеры и email-рассылки.

2. **Встраивание на внешние сайты (Iframe Embed)**:
   ```html
   <iframe src="https://ваш-сайт.ру/?wpo_runner=56" width="100%" height="800" frameborder="0" allow="fullscreen"></iframe>
   ```
   Позволяет встроить олимпиаду в Tilda, Moodle, Stepik, Notion, школьные и вузовские порталы. Сервер автоматически передаёт заголовок `Content-Security-Policy: frame-ancestors *` для бесшовного встраивания на сторонних доменах.

3. **Входящее REST API по ключу олимпиады (`X-API-Key`)**:
   * В карточке есть флажок **«Разрешить входящие запросы к /external/* по ключу»** и блок ключа: маска вида `wpo_6tWP••••••••03Gn`, кнопки **«👁 Показать»**, **«📋 Копировать»**, **«⚡ Сгенерировать ключ» / «♻️ Перевыпустить»** и **«Отозвать»**.
   * Ключ (`wpo_` + 36 символов) **привязан только к своей олимпиаде**: с ним нельзя прочитать или изменить чужую олимпиаду (ответ `403 wpo_api_quiz_mismatch`).
   * Передаётся в заголовке `X-API-Key` (или `Authorization: Bearer <ключ>`). Проверка — через `hash_equals()` по SHA-256-хешу, поиск олимпиады не перебирает все записи.
   * **Перевыпуск** мгновенно создаёт новый ключ и отключает старый, **отзыв** полностью закрывает доступ; в карточке видно дату создания и время последнего использования ключа.
   * Рядом выводится таблица эндпоинтов с кнопками копирования, базовый адрес и готовый `curl`-пример, а кнопка **«🔌 Проверить API»** выполняет реальный запрос `GET /external/ping` с текущим ключом (как это сделает внешняя система).
   * Все запросы `/external/*` требуют ключ: без него — `401`, при выключенном флажке — `403 wpo_api_disabled`, при неверном/отозванном ключе — `401 wpo_api_invalid_key`. Администратор сайта может обращаться к API без ключа из консоли браузера (cookie + REST nonce).

   | Метод | Эндпоинт | Назначение |
   |---|---|---|
   | `GET` | `/wp-json/wp-olympiad/v1/external/ping` | Проверка ключа, версии плагина, доступности олимпиады и списка эндпоинтов |
   | `GET` | `/wp-json/wp-olympiad/v1/external/quiz/{id}` | Структура олимпиады: вопросы без правильных ответов, общие тексты, поля анкеты, баллы и рабочий статус |
   | `POST` | `/wp-json/wp-olympiad/v1/external/start` | Запуск попытки: проверка окна и лимита попыток, анкета участника, `token` + `attempt_id` |
   | `POST` | `/wp-json/wp-olympiad/v1/external/submit` | Приём ответов `answers` по `token` (или `attempt_id`), серверная оценка и результат |
   | `GET` | `/wp-json/wp-olympiad/v1/external/result/{ref}` | Результат и разбор попытки по ID **или** токену |
   | `GET` | `/wp-json/wp-olympiad/v1/external/attempts` | Список попыток олимпиады (`status`, `limit`, `offset`) и общее количество |

   Пример запуска попытки:
   ```bash
   curl -X POST 'https://ваш-сайт.ру/wp-json/wp-olympiad/v1/external/start' \
     -H 'X-API-Key: wpo_ВАШ_КЛЮЧ' \
     -H 'Content-Type: application/json' \
     -d '{"quiz_id": 56, "participant_name": "Иванов Иван Иванович", "participant_email": "ivanov@example.com", "participant_org": "Лицей №1, 10 класс"}'
   ```

4. **Исходящие Webhook-события (с подписью и журналом)**:
   В настройках олимпиады указывается **URL webhook**. При каждой завершённой попытке плагин отправляет `POST` с JSON (ФИО, школа/класс, телефон, город, баллы, максимум, %, статус, длительность, переключения вкладок, время начала/сдачи):
   * отправка выполняется **асинхронно через WP-Cron** (`spawn_cron()` разбудит планировщик сразу) и **не задерживает участника**;
   * тело подписывается **HMAC-SHA256**: `X-WPO-Signature: sha256=HMAC_SHA256("<X-WPO-Timestamp>.<raw_body>", secret)`; дополнительно передаются `X-WPO-Event`, `X-WPO-Delivery`, `X-WPO-Attempt`, `X-WPO-Test`;
   * при сетевой ошибке, `429` или `5xx` выполняется **до 3 попыток** — повторы через 1 и 5 минут (при `4xx` повторов нет);
   * **журнал последних 12 доставок** прямо в карточке: время, событие, номер попытки, HTTP-код, длительность и результат; журнал можно очистить;
   * кнопка **«🚀 Отправить тестовый webhook»** отправляет событие `webhook_test` с примером данных участника и настоящей подписью, показывает HTTP-код, время ответа и подпись;
   * **секрет подписи** создаётся автоматически при сохранении URL, отображается в маске, копируется и перевыпускается отдельной кнопкой; в карточке приведён готовый пример проверки подписи на PHP;
   * совместимо с Telegram-ботом жюри, Google Таблицами / Make / Zapier, внешней CRM или LMS. Школьные системы в локальной сети поддерживаются — приватные адреса не блокируются.

5. **CORS для внешних приложений**:
   Все маршруты `/wp-olympiad/v1/*` отдают CORS-заголовки с разрешёнными `X-API-Key`, `X-WPO-Signature`, `X-WPO-Timestamp`, `X-WPO-Event`, `X-WPO-Delivery`; preflight `OPTIONS` обрабатывается WordPress, поэтому React/Vue/mobile-приложения могут обращаться к API напрямую.

## 5. REST API & AJAX Endpoints

Плагин предоставляет полнофункциональный REST API под пространством имён `/wp-json/wp-olympiad/v1/`:

* `POST /wp-json/wp-olympiad/v1/start` — запуск попытки (проверка окна, регистрация участника, выдача токена и очищенных от ответов заданий).
* `POST /wp-json/wp-olympiad/v1/heartbeat` — синхронизация времени, фиксация ухода с вкладки, проверка на дисквалификацию.
* `POST /wp-json/wp-olympiad/v1/submit` — отправка ответов, серверный подсчёт баллов, сохранение протокола.

**Внешняя интеграция по ключу олимпиады (`X-API-Key`):**

* `GET /wp-json/wp-olympiad/v1/external/ping` — проверка ключа и связи, версия плагина, карточка олимпиады и каталог эндпоинтов.
* `GET /wp-json/wp-olympiad/v1/external/quiz/{id}` — структура олимпиады: вопросы без ключей ответов, общие тексты, поля анкеты, баллы и рабочий статус.
* `POST /wp-json/wp-olympiad/v1/external/start` — запуск попытки из внешней системы (`quiz_id`, данные участника) → `token`, `attempt_id`, вопросы.
* `POST /wp-json/wp-olympiad/v1/external/submit` — приём ответов `{ "token": "...", "answers": { "<question_id>": "..." } }`, серверная оценка и результат.
* `GET /wp-json/wp-olympiad/v1/external/result/{ref}` — результат и разбор попытки по числовому ID **или** токену.
* `GET /wp-json/wp-olympiad/v1/external/attempts` — список попыток олимпиады с фильтром `status` и пагинацией.

Все маршруты `/external/*` защищены ключом олимпиады: `401` без ключа или с неверным/отозванным ключом, `403` при отключённом API и при попытке обратиться к чужой олимпиаде. Ключ никогда не даёт доступ к правильным ответам — вопросы отдаются в публичном виде.

*(Для совместимости с любыми темами также доступны стандартные обработчики WordPress AJAX: `wp_ajax_wp_olympiad_*`)*.

**Ключевые AJAX-обработчики импорта вопросов:**

* `wp_olympiad_validate_import_file` — проверка файла заданий без записи в базу (сетевая папка или загруженный файл); возвращает `stats` (всего строк, к импорту, предупреждения, ошибки, распределение по типам) и `report` (построчный отчёт со статусами и замечаниями).
* `wp_olympiad_run_network_import` — импорт вопросов из сетевой папки (`append` / `replace`), возвращает `stats` и `report`.
* `wp_olympiad_network_sync_status` — только чтение фонового статуса; `manage_options` и `wp_olympiad_admin_nonce`, без паролей и API-ключей.
* `wp_olympiad_sync_desktop_editor` — дополнительное восстановление / обновление редактора в `import/`; обычное размещение выполняется автоматически. Требуются `manage_options` и `wp_olympiad_admin_nonce`.
* `wp_olympiad_deploy_network_templates` — устаревший обработчик: возвращает сообщение об отключении и не записывает файлы; проверка прав и nonce сохранена.

## Участие без регистрации и входа

В настройках олимпиады откройте **«Регламент и расписание олимпиады» → «Участие без регистрации и входа на сайт»** и сохраните. Включённый режим позволяет любому посетителю заполнить анкету и начать опубликованную олимпиаду без WordPress-аккаунта — по прямой ссылке, шорткоду и через iframe.

Если после обновления вы по-прежнему видите старое сообщение о входе, для этой олимпиады сохранён `allow_guest=0`: **включите новый переключатель и нажмите сохранение**. Обновление само не открывает ранее закрытые олимпиады. В новых гостевой доступ включён изначально и больше не теряется при сохранении остальных полей.

Выключенный переключатель требует входа для обычного посетителя и защищён также в REST-start. Административные действия и запись вопросов по-прежнему требуют прежних прав/nonce/ключей. Валидная внешняя интеграция по индивидуальному ключу API работает независимо от WordPress-логина. Даты, лимиты и опубликованность не обходятся гостевым режимом.

## Результаты без проходного порога

В плагине нет проходного процента и автоматического деления на «зачёт/незачёт». Сохраняются **баллы / максимум, процент набранных баллов и статус обработки работы**. Нулевая оценка — такой же завершённый результат, как максимальная; непроверенные ответы сохраняют статус «На проверке». Корректность и баллы каждого ответа не отменены.

**Изменение формата интеграций с 1.0.7:** поля `passed`, `pass_percentage`, `show_pass_pct`, `grading_scales`, `grade_label`, `feedback_message` не передаются. Используйте `score`, `max_score`, `percentage`, `status`; API-ключи, nonce и HMAC-подписи по-прежнему проверяются. В групповом CSV удалена бинарная колонка `Результат`, а `Статус` отражает процесс обработки. В индивидуальном CSV используется `Статус работы`. Ранее выгруженные на NAS файлы автоматически не удаляются; новые экспорты создаются в новом формате.

## Состав экспортной папки вопросов с 1.0.8

> **С 1.0.16 раздел описывает историю (1.0.8–1.0.14).** Экспорт вопросов удалён, файлы `вопросы/` больше не создаются ни одной выгрузкой и снимаются точечно после ближайшей успешной выгрузки — см. «Снятие папки `вопросы/` с 1.0.16».

В `вопросы/` создаются `список_заданий.csv`, `правильные_ответы.csv`, `критерии_и_ответы_<имя>.csv`, `вопросы_<имя>.csv` и `вопросы_<имя>.json`. Последние два сохраняют полный формат и подходят для повторного импорта. Скачивание CSV/JSON на ПК и импорт пользовательских файлов не отключены.

**При следующем успешном экспорте заданий удаляются старые `вопросы/questions.csv` и `вопросы/questions.json`** (с 1.0.14 — только при ручной полной выгрузке или нажатии кнопки «Экспортировать вопросы в сетевую папку»; авто-выгрузка при сдаче эти файлы не трогает) — пользователь явно подтвердил очистку существующих копий. Если вы вручную редактировали эти экспортные дубли, сохраните нужную копию перед обновлением/новой выгрузкой. Никакие одноимённые файлы в import, корне или другой папке не удаляются. Нужны права удаления на NAS/FTP/WebDAV; при отказе выводится ошибка, а не ложный успех. При неудачной записи нового набора старые дубли не очищаются.

Если точный источник автоимпорта был настроен на `вопросы/questions.csv` или `.json`, выберите русский файл выгрузки либо свой файл в import — удалённое имя больше не является источником экспорта.

## Состав и очистка папки `отчёты/` с 1.0.15

Новые выгрузки и ZIP папку `отчёты/` не создают (правило 1.0.11). После успешной записи плагин удаляет три точных имени старой папки — `манифест_выгрузки_<имя>.txt`, `руководство_к_протоколам.txt`, `сводка_результатов.txt` — и убирает саму папку, если она пуста. Никаких масок, рекурсивной очистки и чужих файлов.

С 1.0.15 различаются два исхода:

- **Отказ** — сервер явно сообщает, что объект нельзя удалять безопасно (папка или файл являются ссылкой, каталогом вместо файла, MLSD/LIST показал ссылку, DELETE отклонён). Это по-прежнему ошибка: она видна на странице олимпиады в блоке «Последняя ошибка очистки старых отчётов» и сохраняется до успешной очистки.
- **Непроверяемый ответ** — транспорт не отвечает на проверку (SMB не поддерживает запрос `readlink`, FTP не отдаёт MLSD/LIST, WebDAV не даёт пригодный ETag и заголовок `ETag` в HEAD). Тогда **ничего не удаляется**, а выгрузка считается успешной: в подтверждении появляется предупреждение «Старые файлы отчётов не удалены: …» с объяснением. Папку можно убрать вручную или подключить её как смонтированный каталог — на диске и FTP проверка проходит и очистка выполняется, на SMB она проходит, когда сервер отвечает на `readlink` (обычно так и есть у Samba с POSIX-расширениями).

Дополнительно для WebDAV: если сервер не выдаёт кавычки в `getetag` ответа PROPFIND (так ведут себя WsgiDAV и часть Nextcloud-сборки), плагин читает сильный `ETag` заголовками HEAD и выполняет условный `DELETE` с ним, поэтому старые отчёты теперь действительно снимаются и на WebDAV.

## Снятие папки `вопросы/` с 1.0.16

После **успешной** выгрузки ответов плагин убирает из `вопросы/` семь точных имён прежнего экспорта: `вопросы_<имя>.csv`, `вопросы_<имя>.json`, `критерии_и_ответы_<имя>.csv`, `список_заданий.csv`, `правильные_ответы.csv`, устаревшие `questions.csv` и `questions.json`. Масок, рекурсивного удаления и других папок нет; пустая `вопросы/` убирается, непустая остаётся вместе с чужими файлами.

Механизм тот же, что и для `отчёты/` (1.0.15): отказ транспорта (объект является ссылкой или каталогом, удаление запрещено) и непроверяемый ответ не удаляют ничего и не считают выгрузку неудачной — в подтверждении и в карточке «Последний успешный экспорт» появляется итог «Очистка «вопросы/» не выполнена: …» или «Старые файлы заданий не удалены: …». В отличие от `отчёты/`, здесь нет блока ошибки: выгрузка ответов и снятие старых файлов заданий разделены намеренно.

Импорт не затронут: файлы `import/` (в том числе `questions.csv`, `questions.json` и XLSX учителя) плагин не удаляет и не перечитывает из `вопросы/` автоматически — при настройке автоимпорта на `вопросы/questions.csv` укажите свой файл в `import/` или русский файл выгрузки сохранённого метода.

  * в шапке карточки рядом с весом задания появился индикатор состояния: 🙈 с подсказкой «Баллы скрыты от участников» / «Баллы видны участникам»;
  * существующие вопросы не затронуты: у них состояние определяется сохранённым значением `show_points` (не задано — наследуется глобальная настройка олимпиады).
* **Проверено**: карточка нового вопроса отдаётся с `checked='checked'`; вопрос, созданный через тот же AJAX-запрос, что и кнопка «Сохранить», сохраняется с `show_points = 0` и отображается с индикатором 🙈; существующие 13 вопросов демо-олимпиады остались без изменений; 73/73 теста.

### 1.0.0 — hotfix (17.10.2026): «Не удалось прочитать файл «тест.xlsx» из сетевой папки»
* **Симптом**: при импорте книги Excel, которая лежит в подключённой сетевой папке, плагин отвечал «Не удалось прочитать файл «тест.xlsx» из сетевой папки», хотя файл существует.
* **Причины**:
  * имя файла искалось только точным побайтовым совпадением: кириллические имена с Windows/SMB-хранилищ приходят в CP1251, а macOS хранит их в Unicode-форме NFD — при этом WordPress работает с UTF-8/NFC;
  * поиск шёл только в корне папки и трёх подкаталогах (`import/`, `questions/`, `вопросы/`, `templates/`), без вложенных папок и без учёта регистра;
  * на любую причину (нет файла, нет прав, 0 байт, битый архив) выдавалось одно и то же сообщение.
* **Исправление**:
  * `NetworkImport::read_network_file()` теперь перебирает варианты имени (исходное, NFC/NFD, CP1251, CP866), ищет по нормализованному имени без учёта регистра, а при неудаче выполняет рекурсивный поиск до 3 уровней вложенности;
  * имена из `scandir()` нормализуются в UTF-8, поэтому кириллические файлы корректно отображаются в списке и в отчёте;
  * добавлены точные сообщения: файл не найден (с перечнем доступных файлов), пустой файл (0 байт), нет прав на чтение, ошибка чтения с диска, недоступна сама папка;
  * для книг Excel добавлена проверка контейнера: старый `.xls` или файл с паролем (OLE-подпись) и повреждённый/не-xlsx файл теперь дают отдельные подсказки вместо «не содержит корректных строк»;
  * добавлен **Тест 72** — кириллические имена, вложенная папка, другой регистр, имя в CP1251, пустой файл, отсутствующий файл и реальный импорт по имени.
* **Проверено**: 73/73 теста; импорт книги «тест.xlsx» из подключённой сетевой папки через кнопку «Импортировать вопросы из папки сейчас».

### 1.0.0 — шаблон импорта вопросов: 13 типов, русские заголовки, отчёт о проверке (17.10.2026)
* **Проблема**: шаблон для импорта вопросов описывал только 10 типов заданий, тогда как плагин поддерживает 13. У `slider`, `word_scramble` и `dictation` не было ни колонок в шаблоне, ни обработки в импортёре — их параметры (границы шкалы, лишние буквы, аудио и логика диктанта) при импорте терялись без какого-либо сообщения.
* **Причина**: схема шаблона была продублирована в четырёх местах — CSV-строке, JSON-примерах, тексте README и генераторе Excel; нормализация заголовков была скопирована в `parse_csv_content()` и `parse_excel_content()`.
* **Решение**:
  * добавлен класс `WPOlympiad\ImportTemplate` — единый источник истины по колонкам, алиасам заголовков, алиасам типов, примерам всех 13 типов и сборке CSV/JSON/README;
  * `NetworkImport::get_template_csv/json/readme()` делегируют ему, генератор Excel (`tools/generate_excel_templates.py`) читает схему из `tools/import-samples.json`, который выгружается из этого же класса;
  * в `build_question_from_record()` добавлены ветки для `slider`, `word_scramble` и `dictation`; дублирующиеся карты заголовков удалены;
  * шаблон расширен до 17 колонок (`content`, `image_url`, `shared_text_id`, `template`, `extra`) с понятными русскими заголовками и подсказками;
  * добавлен режим проверки файла без импорта (`NetworkImport::analyze_questions_content()`, `analyze_import_file()`, AJAX `wp_olympiad_validate_import_file`) и кнопки **«✔ Проверить файл заданий»** / **«✔ Проверить файл»** с построчным отчётом;
  * Excel-шаблоны пересобраны под 13 типов и 17 колонок, макрос валидации переписан под все типы и русские названия;
  * добавлен **Тест 71** — проверяет схему, алиасы, CSV/JSON/Excel-шаблоны и сквозной импорт всех 13 типов с проверкой сохранённых параметров каждого типа.

### 1.0.0 — hotfix (17.10.2026): белый экран / HTTP 500 в админ-панели
* **Симптом**: после установки версии с редактором оформления все страницы плагина в админке (`WP Olympiad`, `Параметры олимпиады`, `Конструктор вопросов`, `Протоколы`) отдавали HTTP 500 с сообщением «Сайт столкнулся с критической ошибкой», а сохранение настроек обрывалось.
* **Причина**: в `admin/class-admin.php` (namespace `WPOlympiad\Admin`) использовались классы `Style` и `NetworkImport` без инструкций `use`. PHP резолвил их как `WPOlympiad\Admin\Style` и т.д. — таких классов нет, возникал `Error: Class "WPOlympiad\Admin\Style" not found`. Через WP-CLI ошибка не проявлялась (в CLI `is_admin()` = false, поэтому админ-контроллер не подключался), поэтому интеграционные тесты её не ловили.
* **Исправление**: добавлены импорты `use WPOlympiad\Style;`, `use WPOlympiad\NetworkImport;`.
* **Профилактика**: добавлен **Тест 70**, который сканирует все PHP-файлы плагина, резолвит каждую ссылку `Class::` / `new Class(` с учётом namespace и `use`-импортов и падает, если целевой класс не существует. Теперь такая ошибка не сможет пройти незамеченной.
* **Проверено**: чистая установка из ZIP → активация → все страницы админки 200 OK; сквозной сценарий «старт → сдача → результат 3/3 (100%)»; AJAX-эндпоинты сетевой папки (проверка подключения, шаблоны, экспорт вопросов, сканирование, полный экспорт).

## 7. Установка

1. Скачайте собранный архив `wp-olympiad-1.0.16.zip` (≈ 2 МБ, включает редактор для Windows).
2. В консоли WordPress перейдите: **Плагины → Добавить новый → Загрузить плагин**.
3. Выберите файл архива и нажмите **Установить → Активировать**.
4. В боковом меню появится раздел **WP Olympiad**, где вы можете создавать олимпиады, настраивать регламент, добавлять задания и проверять работы участников.

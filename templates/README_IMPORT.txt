================================================================================
  РУКОВОДСТВО ПО ПОДГОТОВКЕ ВОПРОСОВ ДЛЯ ИМПОРТА (WP OLYMPIAD) — формат 2.0
================================================================================

БЫСТРЫЙ СТАРТ
  1. Откройте questions_template_macros.xlsm (или .xlsx) либо questions_template.csv.
  2. Заполните строки: обязательны только колонки «type» и «title».
  3. Нажмите «✔ Проверить данные» (в .xlsm) или сохраните файл под именем questions.csv.
  4. Положите файл в сетевую папку (каталог import/ или корень) — плагин импортирует его
     автоматически, либо нажмите «📥 Импортировать вопросы из папки сейчас».

ФАЙЛЫ ШАБЛОНОВ
  questions_template_macros.xlsm — Excel с макросами: проверка данных, экспорт CSV, добавление строк
  questions_template.xlsx        — Excel с выпадающими списками и подсказками к каждой колонке
  questions_template.csv         — CSV (UTF-8 BOM, разделитель «;») — самый быстрый способ
  questions_template.json        — структурированный JSON со всеми типами заданий

КОЛОНКИ ТАБЛИЦЫ (порядок важен только для CSV)
   1. type             Тип задания  (обязательно)
      Код типа: single, multi, dropdown, boolean, number, text, matching, ordering, fill_blank, slider, word_scramble, dictation, essay. Можно писать по-русски: «один выбор», «тест», «соответствие»…
      пример: single
   2. title            Текст вопроса  (обязательно)
      Формулировка задания. Обязательное поле. Для fill_blank и dictation допускаются пропуски вида {ответ|синоним}.
      пример: Какая планета является четвёртой по удалённости от Солнца?
   3. points           Баллы
      Целое число баллов за полностью верный ответ. По умолчанию 1.
      пример: 3
   4. penalty          Штраф
      Сколько баллов снимать за неверный ответ. По умолчанию 0.
      пример: 0
   5. group_name       Раздел
      Раздел / часть олимпиады для группировки заданий и навигатора. Необязательно.
      пример: Часть 1: Астрономия
   6. choices          Варианты / пары / элементы
      Варианты через «|». Звёздочка * перед вариантом = правильный. Балл за конкретный пункт: «*Марс^2». Пары: «Франция => Париж». Последовательность: элементы по порядку.
      пример: Венера | Земля | *Марс | Юпитер
   7. correct          Ключ ответа
      Альтернатива звёздочке: номер варианта (2), список (1,3), текст ответа, для boolean — да/нет.
      пример: Марс
   8. target_value     Число
      Правильное число для number и slider. Допускается запятая: 9,8.
      пример: 9.8
   9. tolerance        Погрешность ±
      Допустимое отклонение для number и slider. 0 — точное совпадение.
      пример: 0.1
  10. answers          Синонимы ответа
      Для text — допустимые варианты ответа через «|». Для word_scramble — слово или слова через «|».
      пример: Санкт-Петербург | Петербург | Спб
  11. explanation      Пояснение
      Методический разбор, который показывается после ответа и попадает в протокол.
      пример: Четвёртой планетой от Солнца является Марс.
  12. is_required      Обязательный
      1 — без ответа нельзя завершить тест, 0 — можно пропустить.
      пример: 1
  13. content          Доп. текст (HTML)
      Дополнительный блок под формулировкой: таблица, список, цитата. Обычный HTML.
  14. image_url        Иллюстрация (URL)
      Полная ссылка на картинку к заданию. Необязательно.
  15. shared_text_id   Общий текст (ID)
      ID общего текста/кейса олимпиады (создаётся в конструкторе). Необязательно.
  16. template         Текст с пропусками
      Только для fill_blank и dictation: текст с пропусками {ответ|синоним}. Если пусто — берётся из колонки «Текст вопроса».
  17. extra            Доп. параметры
      Пары key=value через «;». Ключи: min, max, step, extra_letters, audio_url, scoring, mistakes, mode, distractors, min_words, max_words, keywords, min_keywords, match, typo, shuffle, case_sensitive.

РУССКИЕ НАЗВАНИЯ КОЛОНОК И ТИПОВ ПОДДЕРЖИВАЮТСЯ
  Заголовки можно писать по-русски: «Тип», «Вопрос», «Баллы», «Штраф», «Раздел», «Варианты»,
  «Правильный ответ», «Число», «Погрешность», «Синонимы», «Пояснение», «Обязательный».
  Типы: «один выбор», «множественный», «да/нет», «число», «текст», «соответствие»,
  «последовательность», «пропуски», «шкала», «анаграмма», «диктант», «эссе».

ВСЕ 13 ТИПОВ ЗАДАНИЙ
  • single         Какая планета является четвёртой по удалённости от Солнца?
      choices:      Венера | Земля | *Марс | Юпитер
  • multi          Какие из перечисленных элементов являются благородными газами?
      choices:      *Гелий^2 | Кислород | *Неон^2 | Водород | *Аргон^2
      extra:        shuffle=1
  • dropdown       He ___ to school every day.
      choices:      go | *goes | gone | going
      extra:        shuffle=0
  • boolean        Скорость света в вакууме составляет около 300 000 км/с.
      correct:      да
  • number         Чему равно стандартное ускорение свободного падения на Земле (м/с²)?
      target_value: 9,8
      tolerance:    0,1
  • text           В каком городе находится музей Эрмитаж?
      answers:      Санкт-Петербург | Петербург | Спб | Ленинград
      extra:        match=fuzzy; typo=1
  • matching       Сопоставьте государства и их столицы:
      choices:      Франция => Париж | Италия => Рим | Япония => Токио | Бразилия => Бразилиа
  • ordering       Расположите исторические эпохи в правильном хронологическом порядке:
      choices:      Древний мир | Средние века | Новое время | Новейшее время
  • fill_blank     В {=1242|двенадцать сорок втором} году произошло Ледовое побоище на {=Чудском|Чудском озере}.
      extra:        mode=input; case_sensitive=0
  • slider         Укажите, насколько вы согласны с утверждением: «Олимпиада была интересной» (0–10).
      target_value: 8
      tolerance:    1
      extra:        min=0; max=10; step=1
  • word_scramble  Составьте слово из букв: 
      answers:      КВАНТ | КВАНТЫ
      extra:        extra_letters=Ы; case_sensitive=0
  • dictation      Вставьте пропущенные буквы:
      template:     Быстро {=ск|згк}ать по {=лест|лезт}нице.
      extra:        scoring=proportional; mistakes=1
  • essay          Сформулируйте третий закон Ньютона и опишите пример его проявления в технике.
      extra:        min_words=50; max_words=250; keywords=сила|противодействие|отдача; min_keywords=2

КОЛОНКА extra — ДОПОЛНИТЕЛЬНЫЕ ПАРАМЕТРЫ
  Формат: key=value; key2=value2
  min / max / step          — границы и шаг для slider (пример: min=0; max=100; step=5)
  extra_letters             — лишние буквы-обманки для word_scramble
  audio_url                 — ссылка на аудио для dictation
  scoring                   — proportional | all_or_nothing (dictation, essay)
  mistakes                  — допустимое число ошибок (dictation)
  mode                      — input | dropdown | word_bank (fill_blank)
  distractors               — слова-обманки для fill_blank через запятую
  min_words / max_words     — ограничение объёма эссе
  keywords / min_keywords   — ключевые понятия для автопроверки эссе
  match                     — exact | contains_any | contains_all | fuzzy | regex (text)
  typo                      — допустимое число опечаток в текстовом ответе (0–10)
  shuffle                   — 1/0, перемешивать ли варианты ответа
  case_sensitive            — 1/0, учитывать ли регистр

РАЗМЕТКА ОТВЕТОВ
  single / multi / dropdown : варианты через «|», правильные помечаются «*» или номером в correct
  баллы за конкретный пункт : звёздочка + ^баллы, например *Гелий^2
  matching                  : «Франция => Париж | Италия => Рим» (работает также «Франция - Париж»)
  ordering                  : элементы в правильном порядке через «|»
  fill_blank / dictation    : пропуски в фигурных скобках {=верный|синоним|обманка}
  boolean                   : correct = да / нет (или 1 / 0, true / false)
  number / slider           : target_value + tolerance (запятая в числе допустима)

ЧАСТЫЕ ОШИБКИ
  ✗ Пустая колонка «title» — строка будет пропущена.
  ✗ В single/multi/dropdown меньше двух вариантов — строка не импортируется.
  ⚠ В single не отмечен правильный вариант — правильным станет первый вариант.
  ✗ В fill_blank нет фигурных скобок — задание станет обычным текстовым вопросом.
  ✗ Файл сохранён в кодировке ANSI/Windows-1251 — плагин перекодирует автоматически,
    но надёжнее сохранять как «CSV UTF-8 (разделитель — точка с запятой)».

ПРОВЕРКА ПЕРЕД ИМПОРТОМ
  В админке: «Подключение к сетевой папке» → «✔ Проверить файл заданий» (или «✔ Проверить файл»
  в окне импорта конструктора) — покажет отчёт по каждой строке без изменения базы.
  ✓ Готово   — строка корректна и будет импортирована;
  ⚠ Внимание — задание импортируется, но есть замечание (проверьте его);
  ✕ Ошибка   — строка НЕ импортируется, причину смотрите в отчёте.

ИМПОРТ ИЗ СЕТЕВОЙ ПАПКИ
  Сохраните файл в import/, questions/ или вопросы/ — автоимпорт (по расписанию или при
  сохранении) подхватит его автоматически. Режим append добавляет задания, replace заменяет.

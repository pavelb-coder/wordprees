# Зеркало прохождения в localStorage (1.0.27) — как проверялось

## Что это

Возврат в попытку после перезагрузки страницы, реализованный **только на клиенте**: ответ `/start`
(вопросы, таймер, настройки) и введённые ответы лежат в `localStorage` под ключом
`wpo-run-v1:<id олимпиады>`. Сервер про черновик ничего не знает: новых колонок,
маршрутов и статусов в 1.0.27 нет — автосохранение 1.0.22–1.0.25 осталось снятым.

## Где искать в коде

* `public/js/olympiad-frontend.js` — `mirrorKey()`, `storageOk()`, `startMirror()`, `stopMirror()`,
  `recordMirror()`, `scheduleMirror()`, `readMirror()`, `clearMirror()`, `pingAttempt()`,
  `tryRestoreRun()`, общая часть старта `applyRunData(data, remaining)`;
* конструктор запускает восстановление **до** `bindEvents()`, а `handleStart()` ждёт его
  результата — иначе и авто-старт (`skipIntro`), и клик по кнопке создали бы вторую попытку
  поверх восстановленной;
* `initTimer(remaining)` — старт отсчёта от серверного остатка; `sendHeartbeat()` подтягивает
  `remaining_seconds` и во время работы.

## Сценарии `tests/e2e/dom-reload-check.mjs` (48 проверок)

Харнесс поднимает страницу в jsdom на **настоящей** разметке шорткода
(`tests/e2e/fixtures/intro.html`) и с **настоящим** ответом `/start`
(`tests/e2e/fixtures/start-payload.json`); оба файла сняты со стенда WordPress, а не
написаны вручную. Сервер подменён дублем, который считает вызовы и живые попытки.

1. старт: раннер показан, стартовая форма скрыта, зеркало содержит токен и payload;
2. ответ и переход: зеркало обновлено, запросов к серверу — ни одного, `/save` никто не зовёт;
3. F5: `/start` не вызывался (двойной попытки нет), живость проверена `/heartbeat`,
   восстановлены ответы **в форме** (radio отмечен), позиция и серверный остаток времени (05:00, а не 20:00);
4. сдача: восстановленный и новый ответы доехали до сервера, зеркало удалено, показаны результаты;
5. F5 после сдачи: обычная стартовая форма, никакого самопроизвольного старта;
6. попытка уже сдана (404): устаревшее зеркало удалено, старт не заблокирован;
7. сеть лежит (`fetch` бросает): зеркало **сохранено**, исключений нет;
8. `localStorage` недоступен (квота/запрёт): олимпиада работает ровно как в 1.0.21;
9. битая запись вместо зеркала: удалена, страница жива;
10. зеркало чужой олимпиады: игнорируется, запросов нет;
11. зеркало старше суток: сервер не дёргается, запись удалена.

## Второй харнесс: `tests/e2e/dom-skip-intro-check.mjs` (16 проверок)

Отдельный прогон для режима «без стартовой формы» (`data-skip-intro="1"`), где страница сама
запускает попытку при загрузке — именно там риск «F5 заводит вторую попытку» максимальный.
Покрыто: авто-старт делает ровно один `/start` и заводит зеркало; после `F5` `/start` не
вызывается вовсе, попытка проверена `/heartbeat`, ответ отмечен в форме, отсчёт идёт с
серверного остатка (05:00), сдача уезжает с восстановленным ответом и чистит зеркало; если
попытка на сервере уже сдана — авто-старт всё равно состоитя (участник не зависает); при
сетевом сбое зеркало сохраняется. Исключений нет ни в одном сценарии.

**Внимание:** этот харнесс добавлен уже после публикации 1.0.27 и в архив того релиза не
попал — он описывает тот же код, что и `dom-reload-check.mjs`, но приедет в следующем релизе.

## Команды повтора

```bash
# jsdom кладём в персистентный каталог вне снапшота зависимостей
mkdir -p /home/user/qa/deps && cd /home/user/qa/deps && npm i jsdom

cd /home/user/wordprees
node tests/e2e/dom-reload-check.mjs                       # ожидание: «проверок: 48, провалов: 0»
node tests/e2e/dom-skip-intro-check.mjs                   # ожидание: «проверок: 16, провалов: 0»

# negative control: на фронте 1.0.26 харнесс обязан валиться
git show v1.0.26:public/js/olympiad-frontend.js > /tmp/fe.js
cp public/js/olympiad-frontend.js /tmp/fe.keep
cp /tmp/fe.js public/js/olympiad-frontend.js
node tests/e2e/dom-reload-check.mjs                        # ожидание: 21 провал
node tests/e2e/dom-skip-intro-check.mjs                    # ожидание: 8 провалов
cp /tmp/fe.keep public/js/olympiad-frontend.js

php wp-cli.phar eval-file wp-content/plugins/wp-olympiad/tests/test-suite.php --allow-root
# ожидание: ИТОГ ТЕСТИРОВАНИЯ: Пройдено 202 из 202 тестов (100%)
```

## Что харнесс не покрывает

Рендеринг картинок и полей `shared_texts` (не влияет на восстановление), реальную очередь
`/heartbeat` на живом сервере (дубль отвечает сразу), браузерное `sessionStorage`-поведение
при восстановлении сессии вкладки, а также `questions_per_page > 1` — при пачечном выводе
восстанавливается индекс текущего вопроса, а не «первый вопрос пачки».

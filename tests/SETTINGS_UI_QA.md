# Регламент и отключение Email-оповещений — 1.0.3

## Требования пользователя

Удалить блок Email-оповещений **и отключить отправку** участникам/организатору. Перенести «Перемешивать порядок вопросов» в «Регламент и расписание олимпиады».

## Реализация

- Карточка почты и её поля удалены, скрытых параметров рассылки в форме нет.
- В обработчике сдачи больше нет вызова Mailer. Прежняя публичная функция Mailer — no-op; не отправляет письмо даже при старом объекте Quiz с email_participant/email_admin=1. Сохранённые старые флаги не требуют массовой миграции, чтобы перестать действовать.
- В новых настройках оба флага 0. Обработчик обычной формы принудительно сохраняет 0 и пустой прежний адрес организатора, игнорируя присланные старые mail-поля.
- Не добавлены глобальные фильтры почты WordPress. Сбор контактного email, хранение его в попытках/протоколах и системные письма WordPress сохранены. Очереди ранее переданных сторонним SMTP-плагинам писем не управляются этим плагином.
- Единственный checkbox shuffle_questions находится после лимита попыток, внутри #wpo-rules-card. Настройка, её default=0 и сохранённое значение не менялись; отдельное перемешивание ответов остаётся в правой колонке.

## Проверки

**111/111** WP-CLI тестов на WordPress 7.1.3 / PHP 8.4.26 / MariaDB 11.8. Новые 109–111 проверяют defaults, no-op для старых флагов, обычный wp_mail под тестовым перехватом, DOM обеих форм и полноценную сдачу с оценкой/контактом. Прежний тест рассылки изменён на тест её отсутствия.

**19/19** реальных HTTP/браузерных проверок Chromium/Playwright:

1. Новая форма не содержит карточки или скрытых mail-полей.
2. Переключатель ровно один, в выбранном разделе, default выключен.
3. Сохраняются сбор контактов и рандомизация ответов.
4. Нативное создание сохраняет shuffle=1 и оба mail-флага=0.
5. Старая форма отражает shuffle=1 без карточки рассылки.
6. Нативное сохранение выключенного checkbox сохраняет 0.
7. Старые/подложенные mail-поля со значениями 1 не активируют отправку и нормализуются.
8. REST-старт участника с shuffle=0 сохраняет порядок конструктора; сдача завершается.
9. Повторное включение через ту же форму сохраняется. В шести REST-стартах проверены случайный порядок, полный набор ID без потерь и неизменность исходного порядка в БД.
10. Отдельная старая олимпиада с сохранёнными mail-флагами 1/1, **без пересохранения**, успешно принимает попытку, оценивает её и сохраняет контактный email. Ни участник, ни организатор не вызывают wp_mail.
11. Отдельный тестовый системный wp_mail остаётся доступен.
12. На 390 px нет горизонтального переполнения, checkbox видим; нет исключений JS.

Для HTTP-аудита временный MU-плагин вне дистрибутива перехватывает wp_mail и предотвращает реальную доставку. До системного контрольного вызова — **0 событий** после сдач, включая старые включённые флаги; контрольный системный вызов — **1 событие**. Этот MU-плагин удаляется в finally, не входит в ZIP и не является механизмом отключения почты в продукте.

Снимки desktop/mobile просмотрены. Итоговый ZIP устанавливается поверх прежней тестовой версии, после чего полный набор и HTTP/браузерные проверки выполняются для установленного архива. Данные редактора и шаблона Excel побайтово сверяются с 1.0.2. Реальный сайт пользователя не подключался, письма реальным получателям не отправлялись.

# Стилистика+: темы / JSON / эффекты / устройства — 1.0.9

Пользователь выбрал все три предложенных дополнения. Удалённые прежде баннер/кастомный заголовок/slug, порог, Email-оповещения и блок рандомизации не возвращаются.

## Реализация

- Собственные темы — отдельная site-wide option (autoload=false), до 20 имён. Save/update/delete через manage_options + admin nonce. Compare-and-swap сохраняет параллельную запись другого администратора.
- JSON format=wp-olympiad-style, version=1: только нормализованные поля стиля и имя. Нет quiz settings, вопросов/ответов/участников/ключей. До 128 КБ, CSS до 20 КБ. Картинки не встраиваются; URL — часть оформления, перед передачей проверьте их публичность/доступность. Неверный файл не изменяет форму.
- Градиент none/linear/radial с двумя HEX-цветами и углом. Картинка поверх градиента, затемнение поверх фона. Непрозрачность 40–100% меняет только заливку карточки; blur 0–24 px, с fallback заливкой в браузере без backdrop-filter. Defaults none/100/0 не меняют старые стили.
- Старые forms без новых эффектных controls сохраняют их из существующего стиля. Фон выключается существующим явным checkbox.
- Реальный preview iframe без allow-scripts, viewport 1280×800 / 768×1024 / 390×844, масштабируется в панели. CSS генерируется тем же PHP builder, что на странице участника; scoped custom CSS, без @import и опасной разметки. Старые AJAX-ответы fenced/aborted; ошибки не затирают сохранённый стиль.
- Применение темы/JSON меняет форму, не БД олимпиады. Нужен обычный Save. Сохранение/удаление библиотечной темы не перезаписывает стили других олимпиад. Режим устройства не сохраняется в style.

**39/39** реальных HTTP/браузерных проверок Chromium/Playwright:

- Устройства проверены по настоящему window.innerWidth child frame: 1280, 768 и 390. Device toggle не меняет quiz settings.
- Линейный и радиальный preview, два цвета/угол, alpha 0.72 и blur 12; opacity текста остаётся 1. Картинка не скрыта градиентом.
- Нативный Save сохраняет эффект/картинку. Computed background alpha и backdrop-filter страницы участника совпадают с preview, body содержит те же фоновые слои. Гостевая анкета работает.
- Реальная кнопка сохраняет тему в библиотеку без Save quiz. Применение восстанавливает значения. Подтверждённое обновление сохраняет тот же ID, удаление темы не изменяет уже сохранённую олимпиаду.
- Реальный JSON скачан, проверены формат/version/style-only состав. Загружен input[type=file] в другой олимпиаде, применяется только после обычного сохранения.
- Некорректный JSON не стирает поля; файл >128 КБ отклоняется до загрузки; вопросный JSON не принимается.
- Hostile CSS/markup/quiz IDs не запускают скрипт, не скрывают wpadminbar и не добавляют @import. Нет изменения guest/access setting или БД вопросов (SHA до/после совпадает).
- Неверный nonce и anonymous library request отклоняются. Удалённые ранее поля/блоки отсутствуют, 390px без overflow, JS-исключений нет.

Desktop/mobile и реальное оформление участника просмотрены. После установки итогового ZIP полный набор и HTTP/браузерные проверки повторяются; source/ZIP/installed bytes совпадают. Assets редактора и Excel не менялись. Scripts, cookies, fake fixtures/credentials, SQL, логи/скриншоты не входят в ZIP/Git; настоящий сайт/NAS не подключается.

# Два файла в `import/` — версия 1.0.12

## Состав и сохранность

В установочном архиве плагина каталог `wp-olympiad/import/` содержит ровно:

- `QuestionStudio.exe`;
- `question-studio-source-1.0.0.zip`.

На новом пустом сетевом хранилище обычное и принудительное размещение редактора создаёт только эти два файла. Если настроенный путь уже заканчивается на `import`, вложенный `import/import` не создаётся. Исполняемый файл и архив исходников остаются побайтово прежними и проверяются по SHA-256. Плагин не запускает EXE.

По выбору владельца ранее существующие файлы сетевой `import/` **не удаляются**: старые `README_EDITOR.txt`, `EDITOR_LICENSES.txt`, Windows ZIP, `README_IMPORT.txt`, заполненные шаблоны, CSV/JSON, черновики и посторонние папки сохраняются. Поэтому после обновления в старой папке может оставаться больше двух файлов; ненужное можно убрать самостоятельно после проверки. Два указанных файла редактора при размещении могут быть обновлены или восстановлены. При удалённом подключении старое состояние кеша четырёх файлов инвалидируется для новой версии списка.

Кнопки помещения шаблона и инструкции в сетевую папку удалены. Старый AJAX/API-метод возвращает понятную ошибку и не записывает файлы. XLSX-шаблон по-прежнему доступен для скачивания в конструкторе, а пользователь может самостоятельно загрузить его в плагин или поместить в сеть. Работает импорт XLSX/XLSM/CSV/JSON. Дополнительный переносимый архив редактора с инструкцией и лицензиями остаётся доступным из админки; его оригинальные bytes и отдельные лицензионные материалы хранятся вне `import/`, в `editor-resources/`. Отдельная инструкция редактора обновлена с сохранением CRLF и хеша в манифесте. Полные лицензии есть и в оставшемся архиве исходников.

## Проверки на изолированном стенде

WordPress 7.1.3, PHP 8.4.27, MariaDB 11.8.6: **154/154 интеграционных теста**, включая проверку точного состава комплекта, старых и изменённых файлов, вложенных папок, идемпотентности, авторазмещения/импорта, защиты от symlink, отключённого метода размещения, UI и прав/nonce. Проверен переход с прежнего кеша четырёх файлов на два без операций DELETE.

Реальные локальные тестовые filesystem, WebDAV, FTP и SMB: для каждого проверены пустая папка, ранее заполненная папка и подключение непосредственно к `import/`. Два файла редактора совпадают по SHA-256, все прежние данные сохранены после повторного размещения, проверки подключения и экспорта. HTTP-проверка подтвердила скачивание EXE, исходников, Windows ZIP и XLSX, отключение старого AJAX, отсутствие кнопок размещения и защиту прав/nonce.

Реальные сайт и NAS не подключались. Для изменения на сайте необходимо установить ZIP поверх установленной версии без удаления данных. Автоматическая очистка старых отчётов из 1.0.11 при полной выгрузке остаётся без изменений и не затрагивает `import/`.

# Экспорт вопросов удалён, папка `вопросы/` освобождается после выгрузки — 1.0.16

Документ описывает решение владельца и проверки этой правки. История 1.0.8–1.0.14 осталась в `tests/EXPORT_CLEANUP_QA.md`, `tests/AUTO_EXPORT_SCOPE_QA.md` и разделе README «Состав экспортной папки вопросов с 1.0.8».

## Что убрано

- **Кнопка** «📤 Экспортировать вопросы в сетевую папку» в разделе «Подключение к сетевой папке» настроек олимпиады и её обработчик в `admin/js/admin.js` (блок 15f).
- **Файлы заданий из комплектов выгрузки**: `вопросы/критерии_и_ответы_<имя>.csv`, `список_заданий.csv`, `правильные_ответы.csv`, `вопросы_<имя>.csv`, `вопросы_<имя>.json` больше не пишет ни авто-выгрузка при сдаче участника, ни ручная полная выгрузка «📁 В сетевую папку», ни «📦 Скачать комплект файлов (ZIP)`. Состав — `протоколы/протокол_<имя>.csv` и `попытки/попытка_*.csv`.
- **Прямое скачивание вопросов в админке**: адрес `wpo_action=export_questions` (CSV/JSON) закрыт ответом **HTTP 410** с текстом «Экспорт вопросов удалён из плагина…» — по образцу удалённых ссылок на старые образцы шаблонов (1.0.12).

## Что сохранено

- Импорт заданий: `import/`, XLSX/XLSM/CSV/JSON, проверка файла, автоимпорт, размещение редактора — без изменений.
- `NetworkExport::export_questions_to_network()` и AJAX-действие `wp_olympiad_export_questions_to_network` помечены `@deprecated 1.0.16` и продолжают работать для внешних вызовов: тот же комплект пяти файлов и снятие устаревших `questions.csv|json`.
- Параметры `$include_questions` в `NetworkExport::export_quiz()` и `generate_export_files()` принимаются, но игнорируются — прежние вызовы (в том числе `export_quiz($id, $config, true)`) не падают и получают комплект без заданий.
- Ключ результата `questions_included` сохранён и всегда `false`; рядом добавлены `removed_question_files`, `questions_directory`, `questions_notice`.

## Как снимается папка `вопросы/`

После **успешной** доставки файлов выгрузки плагин удаляет ровно семь имён текущей олимпиады: `вопросы_<имя>.csv`, `вопросы_<имя>.json`, `критерии_и_ответы_<имя>.csv`, `список_заданий.csv`, `правильные_ответы.csv`, `questions.csv`, `questions.json`. Масок нет, рекурсивного удаления нет, другие папки (в том числе `import/`) не затрагиваются. Пустая `вопросы/` убирается, непустая остаётся с чужими файлами.

Механизм — общий с очисткой `отчёты/` (1.0.11–1.0.15): `ReportExportCleanup::prune_names()` получает каталог, список имён и формулировку, поэтому для всех транспортов действуют те же проверки — ссылка или каталог вместо файла не удаляются, пустой каталог снимается нерекурсивно, на WebDAV удаление условное по сильному `ETag` (`HEAD`, `If-Match`, без редиректов), а каталог на WebDAV сохраняется намеренно.

Отличие: очистка `вопросы/` **не может сделать выгрузку неудачной**. Отказ или отсутствие ответа транспорта дают итог в подтверждении («Очистка «вопросы/» не выполнена: …», «Старые файлы заданий не удалены: …», «Папка «вопросы/» сохранена…»), `removed_question_files` при этом пуст, блок «Последняя ошибка…» не создаётся. Для `отчёты/` прежнее разделение отказ/непроверяемо сохранено без изменений.

## Проверки на изолированном стенде

WordPress 7.1.3, PHP 8.4.27, MariaDB 11.8.6, Samba 4.22.11, pyftpdlib, WsgiDAV (порт 8131).

- `tests/test-suite.php`: **175/175** на исходниках репозитория. Новые проверки 171–175 (`tests/test-questions-export-removal.php`): точный список семи имён и запрет пути вне папки; пустая папка убирается, чужой файл и файл другой олимпиады остаются; каталог или ссылка вместо файла не удаляются, выгрузка успешна; имя олимпиады без безопасного слага остановившее очистку ничего не удаляет; URL закрыт 410, кнопки и AJAX-вызова в интерфейсе нет. Обновлённые проверки 126, 141, 144, 165–170: пакеты выгрузки и ZIP без `вопросы/`, сохранённый метод пишет пять файлов, конфликт в `вопросы/` не валит выгрузку, сбой доставки по-прежнему не трогает `отчёты/`.
- Реальные транспорты, снятие `вопросы/` — сценарии `retire / emptydir / link / filelink / absent` (18 прогонов: по 5 на filesystem, FTP и SMB, 3 на WebDAV, где проверка ссылок не применима), **0 отказов**: семь имён удаляются, чужой файл и вложенный каталог остаются, пустая папка убирается (на WebDAV сохраняется с пояснением), symlink-каталог блокирует очистку, на локальном пути ссылка снимается без изменения внешнего оригинала, отсутствующая папка не создаётся, повторная выгрузка ничего не удаляет.
- Реальные транспорты, очистка `отчёты/` — прежние 18 сценариев `empty / foreign / link / filelink / missing` после выноса общего механизма пройдены снова, **0 отказов**; 155 транспортных проверок объёма выгрузки (39 на filesystem, FTP и SMB, 38 на WebDAV) подтверждают, что выгрузка по сдаче и ручная выгрузка пишут протокол и попытки, снимают устаревшие `questions.csv|json`, сохраняют рабочий файл преподавателя и старые протоколы.
- Сквозные HTTP-прогоны изолированной среды (скрипты вне репозитория): сдача участника → авто-выгрузка (снятие 4 посеянных файлов, заметка жюри цела, карточка «Последний успешный экспорт» показывает итог) → сохранённый AJAX-вызов (5 файлов) → прямой URL вопросов отвечает 410 → ручная полная выгрузка и ZIP без заданий → вторая сдача ничего не меняет; экспорт с очисткой `отчёты/` (отказ по ссылке, предупреждения, восстановление, nonce/auth) — PASS.
- `php -l` по всем 51 PHP-файлу и `node --check admin/js/admin.js` — без замечаний; при включённых `WP_DEBUG` и `WP_DEBUG_LOG` файл замечаний за прогоны не создан.

Реальный сайт и NAS не подключались. Установка обновления сама ничего не удаляет: файлы `вопросы/` исчезают только после первой успешной выгрузки и только перечисленные семь имён.

## Если эти файлы ещё нужны

- Скопируйте или скачайте папку `вопросы/` из хранилища до первой выгрузки после обновления — после неё плагин снимет семь имён.
- Нужен актуальный комплект заданий? Воспользуйтесь сохранённым вызовом (например, `wp eval` с `NetworkExport::export_questions_to_network()`), либо держите файлы в `import/` — их плагин не удаляет.
- Если автоимпорт был настроен на `вопросы/questions.csv` или `.json`, укажите точный файл в `import/`: удалённые имена больше не обновляются.

# Один основной протокол — 1.0.10

## Поведение и границы

Полная ручная и автоматическая выгрузка, совместимый API формирования комплекта и скачиваемый ZIP создают ровно один файл внутри `протоколы/`: `протокол_<имя>.csv`. Это прежний основной полный CSV с участниками, ответами, оценками, разделителем `;` и UTF-8 BOM. Повторная выгрузка обновляет тот же основной файл.

По выбору пользователя **существующие** `сводный_протокол.csv`, `ответы_участников.csv`, датированные и прочие копии протоколов не удаляются и не перезаписываются. Если в уже используемой папке должны физически остаться только новые основные файлы, организатор должен самостоятельно проверить и удалить ненужные старые копии. Основные протоколы разных олимпиад с различающимися именами сохраняются. Если имена совпадают, используется прежнее правило имени файла; отдельная защита от совпадения имён этим изменением не добавлялась.

Существующее поведение папок `вопросы/`, `попытки/`, `отчёты/`, данные БД и отдельная загрузка CSV не менялись. В частности, прежняя очистка двух английских имён в папке вопросов остаётся в силе (см. `EXPORT_CLEANUP_QA.md`).

## Проверки

На изолированном WordPress 7.1.3 / PHP 8.4.27 / MariaDB 11.8.6:

- **140/140 интеграционных тестов**, включая новые 138–140: состав комплекта и совместимый API; неизменность содержимого, UTF-8 BOM, индивидуальных попыток и вопросов; повторное обновление, сохранность старых копий и другого основного файла; один PUT и отсутствие DELETE для `протоколы/` в WebDAV.
- На реальных локальных тестовых хранилищах filesystem, WebDAV, FTP и SMB дважды выполнена полная выгрузка. На каждом транспорте проверены один новый основной файл, обновление участников и побайтовая сохранность четырёх заранее созданных старых/посторонних файлов.
- В авторизованной HTTP-сессии тестового WordPress выполнена ручная выгрузка, повтор, скачивание основного CSV и комплекта ZIP. В ZIP действительно один файл в `протоколы/`, содержимое CSV совпадает с файлом на диске; анонимное скачивание и неверный nonce отклонены.
- В основном наборе проверена автоматическая выгрузка после сдачи через REST: обновляется один и тот же основной CSV, новая датированная копия не появляется.
- SHA-256 и размер файлов встроенного Windows-редактора сверены с манифестом; они не менялись.

Для повтора интеграционного набора **только на тестовом WordPress**:

```bash
wp eval-file /путь/к/wp-olympiad/tests/test-suite.php --path=/путь/к/тестовому-wordpress
```

Production-сайт и реальное NAS-хранилище не подключались. Обновление плагина само по себе не меняет существующие файлы на NAS.

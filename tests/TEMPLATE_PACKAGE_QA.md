# Комплект шаблона XLSX — проверка версии 1.0.2 (18.10.2026)

> Историческая проверка прежней версии. С 1.0.12 в сетевую `import/` размещаются только EXE и исходники; размещение шаблона отключено. См. `IMPORT_FOLDER_QA.md`.

## Объём изменения

Из установочного ZIP и списка размещаемых шаблонов убраны пять названных файлов: `questions.csv`, `questions.json`, `questions_template.csv`, `questions_template.json`, `questions_template_macros.xlsm`. Размещаются только `questions_template.xlsx` и `README_IMPORT.txt`; четыре собственных файла Windows-редактора сохранены. Никакая автоматическая очистка подключённого хранилища не добавлялась.

Старые пользовательские файлы с теми же именами не стираются и не скрываются из сканирования. По-прежнему можно загружать свои XLSX/XLSM/CSV/JSON и экспортировать настоящие вопросы в каталог `вопросы/`. Изменение касается именно лишних готовых образцов.

## Результаты

**108/108 встроенных тестов** на WordPress 7.1.3, PHP 8.4.26 и MariaDB 11.8. Новые тесты 104–108 находятся в `test-template-package.php`; прежние тесты размещения и Excel обновлены под новый состав. Тест внутренней XLSM-совместимости создаёт валидную macro-enabled OOXML-книгу во временном файле, не поставляя XLSM-образец в архиве.

**31/31 реальная HTTP/браузерная проверка** через Chromium/Playwright и многопроцессный PHP-сервер:

- Открытие настроек не создаёт образцы. Проверка подключения размещает редактор, но ни один шаблон не создаёт.
- Явная кнопка размещает ровно XLSX + инструкцию; UI показывает фактические два файла. Пять удалённых названий отсутствуют в новом каталоге импорта.
- Подключение прямо к `import` не создаёт вложенный `import/import`.
- В окне импорта осталась только ссылка XLSX. Реальное скачивание имеет правильное имя и точные bytes актуального шаблона.
- Ссылки CSV/JSON/XLSM возвращают HTTP 410 без вложения; старая ссылка без параметра формата выдаёт XLSX. Нет пустого скачивания при недоступности XLSX (503).
- Аноним не получает административный шаблон и не может размещать файлы; неверный nonce отклоняется с 403.
- Загружены все 13 типов из четырёх настоящих пользовательских файлов: новый XLSX, сохранённая вне плагина **реальная XLSM-книга с VBA**, CSV и JSON. В БД — 52 вопроса. VBA не выполняется сервером; читаются только данные листа.
- Два реальных входных файла с именами `questions.csv` и `questions.json` сохранены побайтово после размещения шаблона и остаются доступными сканеру.
- На отдельном строгом WebDAV с Basic Authentication переданы только два файла. Проверены обычные разделители `/` (не `%2F`), MKCOL, правильный MIME XLSX и точный SHA-256 удалённой книги.
- При отказе второго WebDAV-файла с HTTP 507 частичная передача не считается успехом; следующий разрешённый запрос восстанавливает комплект.
- В браузере нет исключений JavaScript.

Сборщик шаблонов дополнительно проверяется повторным запуском: он пишет только два разрешённых артефакта, не создаёт CSV/JSON/XLSM, не содержит VBA, не скачивает внешние VBA-заготовки и не копирует файлы в сетевые папки. Импортёру и валидатору всех 13 типов передаются прежние данные схемы.

## Проверка сборки

- `templates/` содержит только `README_IMPORT.txt` и `questions_template.xlsx`.
- В ZIP нет отдельных файлов с пятью запрещёнными именами; состав архива сверяется с исходниками.
- XLSX содержит три листа, списки выбора и подсказки; `xl/vbaProject.bin` и macro-enabled content type отсутствуют.
- Манифест и точные bytes всех пяти assets редактора остаются неизменными.
- PHP lint, синтаксис обоих JS, Python и shell-сборщика проверяются отдельно.
- Итоговый ZIP устанавливается в тестовый WordPress поверх 1.0.1; полный набор и HTTP/браузерные проверки повторяются для установленного архива.

В установочный ZIP не входят реальные HTTP-серверы стенда, управляющие файлы, фикстура старого XLSM, база данных, сетевые пароли, учётные записи, логи и скриншоты. Действующий сайт пользователя и его NAS не подключались. Существующие файлы хранилища автоматически не удаляются — после обновления исчезают только новые создания этих образцов.

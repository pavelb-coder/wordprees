# Удаление карточки «Рандомизация и отображение» — 1.0.4

## Объём изменения

Удалена карточка из правой колонки настроек. Перемешивание порядка вопросов остаётся в регламенте. Сохранённые общие `shuffle_answers` и `show_question_points` не сбрасываются и не меняются из старых полей POST; новые олимпиады используют прежние defaults. Это удаление интерфейсного блока, не отключение индивидуальных настроек заданий.

Требования организации/email по-прежнему настраиваются в редакторе начальной страницы. После удаления карточки каждый из этих контролов присутствует один раз, без прежнего дубля. Блок Email-оповещений и отправка уведомлений остаются отключёнными, как в 1.0.3.

## Проверки

**112/112** тестов плагина на WordPress 7.1.3 / PHP 8.4.26 / MariaDB 11.8:

- DOM новой и существующей форм: нет удалённых блоков, нет скрытых глобальных контролов, shuffle_questions один и в регламенте, требования контактов сохранены без дублей.
- Новый тест 112: частичное обновление не меняет `shuffle_answers` / `show_question_points` для всех четырёх сочетаний 0/1; defaults не менялись.
- Прежние проверки импорта, фоновой синхронизации, редактора и отключённой почты остаются зелёными.

**23/23** реальных HTTP/браузерных проверки Chromium/Playwright:

- Новая форма без карточки и её скрытых полей; перемешивание вопросов находится в нужном месте.
- Новая олимпиада сохраняется штатной HTML-формой без удалённых inputs и получает прежние defaults.
- Для существующей олимпиады проверены все четыре сочетания `(shuffle_answers, show_question_points)`: `(0,0)`, `(1,1)`, `(0,1)`, `(1,0)`. Нативное сохранение без полей сохраняет значения; противоположные старые/подложенные POST-значения не изменяют их.
- Независимое включение/выключение shuffle_questions продолжает сохраняться.
- Требования контактов выключаются и снова включаются через оставшиеся контролы начальной страницы. Реальный участник начинает тест без контактов только при разрешённых настройках; включённые требования дают 400 при отсутствии email и допускают полный корректный запрос.
- Сохранённый режим показа баллов отражается в REST-ответе участника; вопрос и его данные не потеряны.
- Индивидуальные контролы перемешивания ответов и скрытия баллов доступны в конструкторе.
- Мобильная ширина 390 px без переполнения; исключений JS нет.

После установки итогового ZIP повторяются полный набор и HTTP/браузерные проверки. Архив, исходники и установленный плагин сверяются побайтово. Шаблон XLSX и все assets Windows-редактора не менялись. QA-скрипты сервера, управляющие файлы, credentials, логи, изображения и базы в установочный ZIP не включаются. Производственный WordPress и NAS пользователя не подключаются.
